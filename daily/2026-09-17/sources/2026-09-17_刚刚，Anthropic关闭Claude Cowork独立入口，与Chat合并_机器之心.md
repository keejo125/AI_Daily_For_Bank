# 刚刚，Anthropic关闭Claude Cowork独立入口，与Chat合并

来源：机器之心
原文链接：https://mp.weixin.qq.com/s/9QFYRvVKO873mT8bXdIaFw

机器之心编辑部
从今天起，Claude Cowork 和 Claude Chat 将合并为一个统一的 Claude。
无论是提出一个简单的问题，还是把一份中午截止的报告交给 Claude 处理，Claude 都可以接手完成任务，即使你已经关闭了电脑，任务也会继续进行。
这一功能将在未来几周内陆续向 Pro 和 Max 计划用户开放，之后还会覆盖更多套餐。
Claude 创建的内容也不再需要单独的存放空间，Claude Docs 和 Claude Slides 一并正式推出，同时，Claude Design 也已经可以直接在对话中使用。让 Claude 创建一份文档，你可以和 Claude 一起协作完成；让 Claude 制作一份演示文稿，Claude 会直接帮你起草幻灯片。
你可以直接在 Claude 中编辑内容，从 Claude 里直接进行演示，或者将文件下载为 PowerPoint 或 PDF 格式。这三项功能目前都处于 Beta 测试阶段，面向付费用户开放。对于企业用户，管理员可以决定何时开启这些功能。如果你单独使用 Claude Design，它仍会继续按照此前的方式运行。
Anthropic 表示，此前 Cowork 被设计为处理大型任务的独立工作空间，而 Claude Design 则主要面向视觉创作场景。用户在实际使用过程中会同时调用两者，但反馈称，最大的问题在于需要判断任务应该交给哪个工具完成，而且在一个工具中开始的工作也无法自动延续到另一个工具中。
为此，Anthropic 不再要求用户提前选择工具。如今，Claude 能够根据任务需求自动判断所需能力，让 Cowork 和 Design 的功能可以直接在任意对话中调用，同时继承用户已有的上下文、技能和连接器。
使用场景
一份每周报告需要在中午提交。出门前，你向 Claude 询问上周业务管线有哪些变化，然后补充一句：
按照我们一直使用的方式来写，标记出所有延期的事项，并把重点整理成 5 页幻灯片，用于管理层会议。
如果有任何不明确的地方，Claude 会主动询问。你可以在前往办公室的路上通过手机查看进度。
等你坐到办公桌前，报告已经整理成文档形式，其中包含同事留下的备注；演示文稿也已经准备好，可以直接打开、调整，并下载为 PowerPoint 文件。
由于两者都来自同一次对话生成，幻灯片内容已经与报告保持一致。
你可以自行修改其中一句话，在某页幻灯片上给 Claude 留下一条评论，然后分享出去。
如果你将这项任务设置为每周一自动执行，Claude 之后无需再次提醒，就会主动开始准备报告。
你使用 Claude Design、Slides 或 Docs 创建的所有内容，都会集中在一个可分享的链接中，你可以直接在手机上打开查看。
你可以选择某个元素并移动它，也可以直接告诉 Claude 你希望修改什么内容。
你还可以决定 Claude 与你沟通确认的方式。默认情况下，Claude 会在执行操作前询问你的确认。如果你更希望让 Claude 持续执行任务，只在遇到需要你重点查看的情况时再与你沟通，也可以开启这一模式。
最终决定权始终掌握在你手中。
开始使用
如果你平时主要使用聊天功能，不需要做任何改变。当你想把一个更复杂的任务交给 Claude 处理时，可以尝试让它完成下一份你通常会亲自制作的报告或演示文稿。
如果你之前一直在使用 Cowork，那么所有内容都会保留在原来的位置：包括你的聊天记录、项目、生成的内容（artifacts）、连接器（connectors）以及技能（skills）。打开应用后，你可以直接从之前中断的地方继续工作。
这项功能将在未来几周内首先向 Pro 和 Max 计划用户推出，覆盖 Claude 网页版、桌面端和移动端应用，包括现有用户和新用户。用户无需手动开启任何设置。
之后，Team 和 Free 计划也将陆续获得支持；对于 Enterprise 用户，管理员将在组织设置发生任何变化前至少 30 天收到通知。
完整的功能列表可以在帮助中心查看。
如果你一直积攒着一个复杂、混乱的大项目，现在正是交给 Claude 处理的时候。
这一更新也引发了不少讨论。有网友认为，Claude 这是打算与微软正面交锋了。
还有人认为：这简直要把那些搞人工智能相关幻灯片展示的初创公司给搞垮了。
