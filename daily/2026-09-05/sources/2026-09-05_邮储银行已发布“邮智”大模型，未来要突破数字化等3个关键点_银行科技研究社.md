# 邮储银行已发布“邮智”大模型，未来要突破数字化等3个关键点

来源：银行科技研究社
原文链接：https://mp.weixin.qq.com/s/cvCEm52gRpmAON3UcZt2SQ

近日，邮储银行发布2026半年报。半年报显示，报告期内，该行营收1924.82亿元，同比增长7.26%；净利润516.71亿元，同比增长4.57%。
而AI技术早已是邮储银行关注的重点。在半年前的2025年报业绩发布会上，邮储银行副行长兼CIO牛新庄就介绍，该行已经组建超千人的人工智能创新型团队，实现人工智能应用从业务需求、技术研发到场景落地的一体化推进。
在近期发布的2026半年报中，AI依旧是邮储银行介绍的重点。
已发布“邮智”大模型，模型上线周期缩短至1天
至报告期末，邮储银行大模型能力已接入超90个行内系统，日均调用超600万次，日均输入输出Token超百亿，已落地超370个大模型应用场景。
据悉，邮储银行已经发布“邮智”金融行业大模型，该大模型在通用大模型能力基础上，根据金融业务特点形成客服、安全、风控等细分领域百亿参数规模的垂域模型矩阵。其通过重构模型架构、压缩模型参数规模、优化推理框架工程等技术，打造小参数、强能力、轻量化的金融垂域模型，缓存占用整体下降约72%，推理成本最高节省超87%。同时“邮智”大模型沉淀出可复制、可迭代的场景建设模式，模型上线周期由2周缩短到1天。
在2026半年报业绩发布会上，牛新庄进一步介绍，上述“邮智”大模型是该行联合华为共同发布。
在具体业务方面，零售领域，该行零售营销智能体可以动态生成个性化营销方案，触达超5400万名邮银高潜客户；对公领域落地智能产业链展业助手，规划建设十余个场景智能体，辅助对公开户超6000户、授信超2000户，授信金额近3100亿元。此外，已经推出货币市场AI交易机器人“邮小助”、交易员助理机器人等场景的AI应用。
经营管理方面，将AI深度嵌入识别、审核、风控等运营管理关键节点，运营中心单据智能识别替代手工录入比例达90%，小邮助手智能问答占总问答量比例超98%，防电诈模型预警账户风险分析效率提升近30%；打造贯穿前中后台的智能信贷支撑体系，前台赋能客户经理尽调与方案生成，中台打造信审助理实现智能审查，贷后强化智能监测与自动化处置能力，尽职调查工作效率提升超50%；并围绕日常办公核心环节，建成多个办公专用智能体，累计提供对话服务超50万次。
科技支撑方面，打造需求、研发、测试、运维、问数等全流程科技智能体，智能编码系统、智能测试系统占比均超60%，运维智能体查询耗时压缩至1分钟内，威胁攻击研判耗时从分钟降低至秒级。
数据管理方面，以“AI for Data”模式助力数据管理体系升级、数据资产价值释放，截至报告期末，邮储银行已打造智能问数、智能找数等6大类50余个场景。
在大秀AI“成绩单”的同时，邮储银行正继续推动对AI、科技研发等的布局。
将继续发力AI、科技研发等，未来要突破数字化等3个关键点
据《银行科技研究社》了解，6月底，邮储银行召开2025年度股东会。彼时，牛新庄就强调，至2026年底，该行计划日均大模型调用次数将超千万次，Token吞吐量超300亿。此外，邮储银行还曾在报道中表示，计划今年底实现1000个大模型应用场景。
与2026半年报披露的数据对比，上述提及的三个年底目标中，大模型调用次数及应用场景、Token吞吐量均是现有“成绩”的两倍左右。这意味着，该行下半年将继续发力AI。
此外，科技研发或也是邮储银行数字化转型的重点。
今年上半年，邮储银行发布了多个雄安研发中心项目相关采购信息。相关信息显示，邮储银行雄安研发中心项目正在推进中，相关土地出让成交价约1.7亿，其将耗资数亿元布局研发中心。
提及“数字化”，邮储银行行长芦苇在2026半年报业绩发布会上直言，这是该行接下来最需要突破的三个关键点之一。而三个关键点包括：
一是收入结构加快转型，“息差收窄是行业性趋势，虽然我们的净息差1.63%仍在大行中领先，但同样面临压力”，必须加快培育非息“第二增长曲线”，构建“穿越周期的收入增长新结构”；
二是数字化从“工具”走向“能力”，下一步要真正把数据变成资产，把AI变成生产力；
三是组织和人才的适配，战略落地最终要靠人，要让基层的活力释放出来。
值得注意的是，上述提及的三个关键点中的“第二增长曲线”，与财富管理等领域密切相关。邮储银行2026半年报指出，其未来要做强财富管理“第二增长曲线”，具体看，将持续优化理财产品供给，依托“资产配置+1”常态化、体系化落地，推动业务从单一产品销售向专业资产配置顾问转型。
而财富管理业务转型离不开AI等技术的应用。据悉，邮储银行已经升级“云帆”财富管理数字化支撑平台，依托全行自研大模型，搭建理财经理全流程AI赋能体系，落地AI话术实景演练、线上智能会客室、AI投研导读等场景应用。
子公司方面，中邮理财上线投研报告智能撰写、合规制度智能比对、舆情风险智能标识等16个大模型应用场景；在运营领域，研发理财产品审计报告等非结构化数据自动解析核验工具，耗时缩短近90%；并探索AI智能编程，依托智能化工具完成股债策略回测等功能，推动开发周期由月结压缩至日结，研发效率提升超80%。
未来，在行业转型大势和技术推动下，邮储银行的业务和技术布局，值得更多关注。
