# Kimi Code Desktop 正式与你见面

> 原文链接：https://mp.weixin.qq.com/s/0x-tXOxlutrxE9YNODng0A
> 来源：月之暗面 Kimi

今天，Kimi Code Desktop 正式与你见面。
macOS
和 Windows 版同步上线，
访问 kimi.com/code 开始安装使用。
作为 Kimi Code 官方桌面客户端，它将 Kimi Code 智能编程服务能力带到桌面应用中。你不仅可以在桌面端内直接使用 Kimi Code 的 AI Agent 能力，通过对话让它
读写代码、运行命令、完成自动化任务
，还能在全新可视化的图形交互界面中，集中管理你的所有项目，调整常用配置，清晰查看 Agent 执行任务的每一步。
无论是快速验证想法，从零开发个人应用，还是在大型代码库中推进复杂的工程任务，告诉 Kimi Code Desktop 你的想法和要求，它就可以
制定可评审、可反馈的执行计划，然后围绕目标持续推进，直至完成任务并交付结果。
针对开发者的实际工作流，桌面端还提供
内置终端、浏览器和 Git 状态查看
等功能，支持直接运行和调试项目、审阅代码改动，关联 PR 状态，方便跟踪代码评审与合并进度。
如何安装和使用？
第一步：下载并安装 Kimi Code Desktop
下载地址：
kimi.com/code
，目前已支持 macOS
（Apple + Intel 芯片）
、Windows。
第二步：一键登录 Kimi Code 账号，或配置第三方模型供应商
作为 Kimi Coding Plan 的官方搭配 Agent，更推荐在 Kimi Code Desktop 直接登录使用，套餐用量随时可查。登录 Kimi 账号后，桌面端会使用账号可用的官方模型。你可以在输入框内的模型选择区域确认当前模型，也可以在设置中的模型模块查看可用模型和模型权限。
第三步：选择一个文件夹作为工作区
桌面端会按工作区整理会话。新建会话后，可以在输入框下方选择要使用的本地项目文件夹。
从 CLI 到 Desktop，
你熟悉的 Kimi Code 更加清晰可控
如果你已经是 Kimi Code CLI 的老朋友，来到 Kimi Code Desktop 后，本地的 CLI 任务会直接出现在桌面端，你所熟悉的 Agent 能力也依然保留。
从边界清楚的小任务，到尚待拆解的长期目标，再到可以并行推进的复杂工程，你都能找到合适的工作模式，让 Agent 从规划和执行一路推进到结果交付。
对于影响范围较大、需要先确认方案的任务，可以开启
Plan 模式
。Agent 会根据你的要求先完成分析并给出执行计划，经你审阅、反馈和确认后再开始动手。
为 Agent 设置一个
Goal
，它会围绕明确目标持续执行和检查，适合需要多轮推进的长任务。
启用
Swarm 模式
后，主 Agent 会将任务拆分成多个子任务，在需要时调度 Subagent 分工处理，并汇总各自的工作结果。
如果希望进一步尝试多 Agent 协作，还可以开启实验性的
Tower 模式
，让多个 Agent 围绕同一目标并行推进，适合规模较大、可以拆分的工程任务。
有了 Desktop，Kimi Code 也拥有了
直观的图形界面和流畅的交互体验。
原本需要在终端中输入命令才能执行任务、查看文件、管理会话或修改 config 文件，如今这些操作都可以集中在一个窗口中完成。
过程清晰可见：
随时查看 Agent 的工具调用、执行进度和代码改动。
文件一点即开：
聊天中提到的文件路径可以直接点开并预览。
会话清晰有序：
标签页、置顶、批量管理、AI 自动命名、全局搜索，再多会话也不乱。
配置直接调整：
在设置面板中管理 Agent 的默认模型、模型供应商、权限和插件等常用配置。
深入实际开发流程，
让执行、审阅与交付顺畅衔接
作为面向开发者的编程智能体，Kimi Code Desktop 也充分考虑了真实开发中的工作流。你可以在同一个窗口里运行项目、验证效果、审阅代码，并跟进后续的 Git 与 PR 状态。
当任务产生修改后，你可以在
右侧面板
按文件或单轮修改审阅具体差异，并预览 Markdown、JSON、HTML等多种代码和文本文件。需要继续追问时，还可以在侧边展开对话，无需离开主会话。
内置终端
让开发者可以直接在 Desktop 中执行构建、测试和格式检查等验证命令，也可以查看 Git 命令输出。
桌面端还支持
截图标注
。框选屏幕区域，写句评论发给 Agent，无论是页面错位、报错信息还是设计细节，都能让 Agent 直观看到问题，准确理解你的需求，指哪改哪。
需要验证网页效果时，可以直接打开
内置浏览器
预览。Agent 可以直接操作浏览器，完成页面交互和效果验证、资料查找等任务。你还可以标注网页中的元素或区域，自动捕获元素信息并附上截图和评论，让 Agent 准确定位要修改的位置。
在 Git 项目中，Git 状态区域还可展示当前分支、领先与落后状态、文件变化及相关 PR 状态，方便跟进代码评审与合并进度。
从 CLI 到 Desktop，我们希望 Kimi Code 走向更多用户，进入更多样的场景。
在持续提升模型能力的同时，也通过清晰可见、随时可控的协作过程，建立与 AI 之间更稳固的信任关系。期待 Kimi Code 成为与你一起把想法变成现实的开发伙伴。
Kimi Code Desktop 1.0 只是一个开始，更丰富的功能持续开发中。还有更多能力和用法，等待你在自己的项目中亲自体验和发现。点击「阅读原文」，即可前往下载安装页面。
