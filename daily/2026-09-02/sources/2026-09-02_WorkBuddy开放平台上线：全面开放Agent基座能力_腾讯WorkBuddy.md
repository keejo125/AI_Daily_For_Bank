# WorkBuddy开放平台上线：全面开放Agent基座能力

来源：腾讯WorkBuddy
原文链接：https://mp.weixin.qq.com/s/vZiiXVTNM_RSmeAQyQSXXQ

今天，WorkBuddy开放平台正式发布上线，首批引入超百家生态伙伴，面向智能硬件、行业应用与开发者等全面开放底层 Agent 能力。这也是国内 AI Agent 赛道首个同时打通硬件、应用、开发者三层生态的开放平台。
“我们希望把 WorkBuddy 打造成面向 Agent 时代的操作系统——不是做一个更强的工具，而是做一个能承载所有工具的平台。”
——
腾讯云副总裁、
腾讯CodeBuddy
&WorkBuddy负责人刘毅
硬件共创：
一次接入，多端流转
围绕“听、看、记、聊、协”五类触点，WorkBuddy 已接入智能眼镜、录音卡片、耳机、键鼠、PC 与平板、智能穿戴、手机等十余个品类，超过 30 个品牌。厂商无需自建 AI，也不必改变产品形态，一次接入即可打通硬件、App、PC、Web 多端。
首发的 9 款联名硬件来自 Plaud、乐奇Rokid、影石、优篮子、科大讯飞、安克、猛玛、京东京造等品牌，多为各自品类中首次接入 Agent。
以智能眼镜为例：眼镜负责采集，WorkBuddy 负责理解、规划与执行——戴着它进会议室，转写、纪要、待办一条链路走完。
行业连接：
「Buddy应用」发布
同时，「Buddy应用」正式上线，伙伴可以基于 WorkBuddy Agent 底座能力，结合自身行业知识和经验积累，构建自己的品牌化 AI 工作台。伙伴无需自研 AI，只需把场景、业务上下文、工具能力与品牌接进来，就能获得完整形态的 AI Agent 办公产品。
目前，Buddy应用已覆盖金融、SaaS、法律、医疗、教育、公益、设计等 20 多个领域，由通达信、广发证券、腾讯SSV、腾讯健康、北大法宝等 30 多个伙伴共建。
开发者：
技能、专家、连接器全开放
WorkBuddy 开放平台同步开放 Skill（技能）、Expert（专家）、Connector（连接器）三大能力，调用标准 API 即可获得完整 Agent 能力。Expert 市场涵盖 Agent 型与 Team 型两种形态，Connector 支持 MCP 与 CLI 双方案。支付与分发通路也在加速建设，让专业经验得到更好回报。
打造Agent基座
共创行业新标准
Agent 如今已经 “能做事”，成为了大家工作生活提效的得力助手；但围绕用户无处不在的真实需求，真正的挑战是让它在任何设备、任何系统、任何场景里都不中断，让 Agent 能力触手可及。
腾讯 WorkBuddy 此次发布开放平台，开放 Agent 底座能力，就是希望联合生态伙伴共建行业新标准，让每一位伙伴都能把 Buddy 接进自己的场景。
自今年 3 月初上线至今，WorkBuddy 已完成 50 多个版本迭代，成为最受用户欢迎的 AI 办公智能体，已在政务、教育、零售、金融、传媒、出行等 50 多个行业加速落地。
未来，我们欢迎更多开发者与伙伴，一起把 WorkBuddy 带进真实场景，共同打造 AI Agent 办公新范式。
WorkBuddy开放平台网址：open.WorkBuddy.cn
