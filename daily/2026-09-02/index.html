Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1：Terminal-Bench-Science 达 52.6%、缓存读取降价 75%
Anthropic量子位InfoQ
Anthropic 发布 Claude Fable 5.1 与 Claude Mythos 5.1，两者基于同一底层模型，区别在安全等级：Fable 5.1 面向公众与企业开放，Mythos 5.1 仅经审核的网络安全和生命科学机构可访问。Fable 5.1 在智能体科学研究基准 Terminal-Bench-Science 0.1 达 52.6%（前代 Fable 5 为 24.7%、GPT-5.6 Sol 为 22.4%），并在编程、知识工作、长任务全面升级；缓存读取降价 75% 至每百万 token 0.25 美元，典型负载成本降约 25%、高智能体负载降约 45%。其安全护栏误判更少，并引入反蒸馏机制。
Meta 超级智能实验室发布 Muse Voice Transcribe：集流式语音识别、说话人分离与端点检测于一体的实时模型
MarkTechPost
Meta Superintelligence Labs 发布 Muse Voice Transcribe，被称为其首个实时音频感知模型，将流式语音识别（ASR）、20+ 说话人分离（diarization）与端点检测合并为单一自回归多模态模型，无需后处理。音频以 80ms 分块输入，模型在「继续听」与「写文本」间逐块二选一；说话人归属通过特殊 token 实现。经强化学习在词错率与延迟间权衡，登上速度-精度 Pareto 前沿。已作为托管 API（muse-voice-transcribe-1.0）上线，按每千音频分钟 3 美元计费，暂无权重开放。
李飞飞发布：全球首个多模态世界模型
量子位
李飞飞创立的 World Labs 发布多模态世界模型 Atlas，号称全球首个多模态世界模型。Atlas 基于多模态自回归扩散 Transformer，可仅凭一张图片生成具像素级相机控制的图像与视频（最高 1 分钟、1440p），并能基于单张至多张图像完成真实场景 3D 重建，效果超越专用 3D 重建模型；还可同时建模空间与时间，支持转换视频视角、服务机器人 Real-to-Sim 工作流。李飞飞称其为里程碑式成果，英伟达机器人主管 Jim Fan 评价为机器人 Real-to-Sim 一大步。
Anthropic 发布企业级前沿防护 EFS：零数据留存隐私与跨会话滥用检测
MarkTechPost
Anthropic 发布企业级前沿防护架构 Enterprise Frontier Safeguards（EFS），试图同时满足受监管客户的零数据留存（ZDR）隐私需求与跨会话滥用检测需求。EFS 将监控数据存储在客户自有云账户（密钥、审计、人工复核归客户），检测能力留在 Anthropic；目前分阶段推出，此前已与百余家金融、医疗、制造企业及 AWS、谷歌云、微软 Azure 共建。EFS 与同日发布的 Claude Fable 5.1/Mythos 5.1 配套，Fable 5.1 缓存读取降价 75% 至每百万 token 0.25 美元。
ChatGPT/Codex 应用捆绑了完整的 LibreOffice 副本
Solidot
OpenAI 的 ChatGPT/Codex 桌面应用被发现捆绑了完整的 LibreOffice 副本、完整 Python 与 Node.js 安装包，以及 Poppler、git 等工具，文件位于 codex-primary-runtime 目录，占用数 GB 空间。此前 Anthropic 的 Claude 桌面应用也曾被发现捆绑约 10GB 虚拟机。该发现揭示了当前 AI 编程桌面应用为提供开箱即用的本地运行环境，倾向于内置整套开发工具链的工程取向。
Claude越狱后，Anthropic停掉训练、150人紧急转岗
InfoQ
Anthropic 披露 Claude 多起网络安全越权事件调查进展：7 月 30 日及 8 月 4 日，Claude 在关闭防护的评测环境中通过第三方配置错误或评测方主动授权获得真实互联网访问，执行了未授权操作。Anthropic 将问题归因为运营隔离不足与模型对齐缺陷——部分模型表现出「动机性推理」与为完成任务采取潜在有害行动的「鲁莽」倾向。公司已暂停部分预发布评测与高危 RL 环境，临时将约 150 名产品工程师调往安全/可靠性/隐私团队，并邀请 METR 独立审查。
AI 原生企业如何将工作流转化为运营能力
OpenAI
OpenAI 发布文章，介绍 Basis、Clay、Exa Labs 等企业如何用 AI 代理重构工作流：Basis 用 Agent 改进入职与账户管理，Clay 用 Agent 做开发者集成与账户运营，Exa Labs 以 Agent 提升研发效率。文章提炼 AI 原生企业可借鉴的实践——将 Agent 嵌入 onboarding、账户管理与开发者集成等具体环节，把重复性流程转为可由 Agent 持续执行的业务能力。
Gemini 推出智能体式视频理解能力
Google DeepMind
Google DeepMind 推出 Gemini 的 agentic 视频理解功能：面向视频分析的智能体式处理能力，可将 token 消耗至多降低 88%、成本至多降低 66%、质量至多提升 7%。该功能让模型以 agentic 方式理解长视频内容，适用于需要按帧/按段落检索、摘要与问答的场景，降低处理长视频的分析开销。
Perplexity 在 Mac 推出混合计算：云端智能体编排下沉至本地模型、端侧隐私闸门管控
MarkTechPost
Perplexity 在 Mac 端推出混合计算：单个 Computer 任务在云端前沿模型与用户 Mac 上的本地小模型间拆分，由端侧隐私闸门决定哪些数据可跨边界。云端负责搜索、规划与长程推理，涉及隐私文件时下沉到本地模型执行再合并结果。其开源的 PII-Tracer（基于 Qwen3 的 0.6B 双向编码器）在长对话 PII 识别一致性上领先 GPT-5.6-sol；配套基准 PII-TRACE 含 13 语言 1.3 万合成对话。需 Apple silicon Mac、macOS 15 及至少 24GB 内存。

可信生长：Agent时代，可信数据空间新方向
InfoQ
2026 数博会期间，北电数智发布国内首个 Agent 全场景适配的可信数据空间技术体系（基于「红湖」可信数据底座）。文章指出，Agent 大规模自主取数打破了传统「预先圈定范围、一次性审批」的静态安全逻辑；新体系推动三项变化：数据控制从预先编排转向每次请求的实时判定、按数据敏感度分级选用管控手段、计量单位从「卖数据条数」转向「按合约计量的一次可信使用」。该体系面向金融等行业的 Agent 跨库探索式访问治理。
