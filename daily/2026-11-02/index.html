66 岁 Yann LeCun 发新论文挑战 Scaling Law：1.09 亿参数胜过 720 亿，模型越大不一定越懂世界
InfoQ
Meta 首席科学家 Yann LeCun 与布朗大学 Randall Balestriero 发布 37 页论文《Proving and Improving the Platonic Representation Hypothesis with JEPAs》，论证不同模态模型即便独立训练也能学到可对齐的世界表征。实验显示，仅 1.09 亿参数的文本 JEPA 在跨模态表征对齐测试中超过 Qwen2.5-72B、Llama-3-70B 等大模型，参数相差约 660 倍；新方法的模型仅用 2160 万样本即达到下一 Token 预测模型需 9 亿样本的对齐水平（约 42 倍差距）。论文并非否定 Scaling Law，而是为「世界模型」路线提供理论支撑，提示行业在追求规模之外也需关注表征质量。

qwenGPU：将 GPU 编译进 Qwen3.5 权重的实验模型
MarkTechPost
开发者 Vixhal 在 GitHub 以 MIT 许可发布实验模型 qwenGPU：把一块 SIMT GPU 直接「编译」进 Qwen3.5-2B 的权重中，使其在前向推理过程中运行真实 CUDA（编译为 NVIDIA PTX）。模型由 Qwen3.5-2B（24 层）外加 45 个编译得到的 GPU 层共 69 层组成，上下文 262144 Token，可在 Apple 芯片、NVIDIA GPU 或 CPU 上以约 16GB 空闲内存运行。其思路是让精确计算发生在预训练 LLM 内部而非其外部，作为对「模型内计算」可行性的技术验证。

OpenAI重写大模型法则，第一条：忠于人类！！
量子位
OpenAI 更新模型准则（Model Spec），列出 5 条核心价值观，首条即「忠于人类意图」。其余四条为减少伤害、诚实透明、促进人的自主性、关怀。准则强调「忠于意图」而非「忠于指令」：死板执行字面命令本身被视为失职，模型需结合任务目的、对话上下文、记忆与用户历史判断真实诉求。文中举例，当小孩询问「牙仙子是否真的存在」时，应超越字面回答理解其潜在需求。这份约 5 万字的准则，意在为模型安全与价值对齐提供更细的行为规范。

如果 AI 幻觉也有预算，超支之后该怎么办？
InfoQ
Grafana Labs 提出用可靠性工程方法衡量 AI 智能体表现：以评估、服务级别目标（SLO）与错误预算，将幻觉、任务完成度、毒性、成本等行为转为可监测的目标。传统可观测性只能说明响应快、无报错、耗了多少 Token，却无法判断答案是否正确、是否基于给定上下文、对用户是否有用。Grafana 的方法是先评估每次交互是否满足特定行为标准（可用 LLM 裁判或正则等确定性检查），再转化为可对照 SLO 的 SLI；它反对单一「智能体质量分数」，强调分维度、可持续监控。
