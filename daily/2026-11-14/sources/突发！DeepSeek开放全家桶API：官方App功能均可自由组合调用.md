# 突发！DeepSeek开放全家桶API：官方App功能均可自由组合调用

来源：量子位
原文链接：https://mp.weixin.qq.com/s/gHvlpHNPU1W-ASCm24yJbg

一水 发自 凹非寺
量子位 | 公众号 QbitAI
周五晚上搞事，D老师通通都不藏了！
就在刚刚，DeepSeek宣布，
正式开放全家桶应用API
。
什么意思？
以前大家在DeepSeek App里用得顺手的联网搜索、深度思考搜索、文件上传、链接阅读等功能，现在开发者通过API通通都能直接用上了，而且不必打包使用，它们都有独立接口，支持单独调用、分别计费。
划重点，
语音能力也首次加入开放行列
，包括语音识别、语音合成等接口。
官方还放出一句相当有意思的话：
开发者甚至可以1:1复刻出完整的DeepSeek App
。
不是哥们，连自家产品都允许别人照着做啊？？
DeepSeek还贴心亲自打了个样，直接开源了一套轻量级聊天前端Demo，支持导入DeepSeek历史对话。
也就是说，开发者不用再从头折腾搜索、文件解析、语音识别这些基础功能，就能快速搭出一个功能接近DeepSeek App的产品。
消息一出，评论区也是相当热闹。
有网友直接感叹：
什么叫1:1复刻出完整的DeepSeek App？？？人工智能之光！
全家桶应用API开放一览
具体来看，这次DeepSeek一口气开放了这些能力：
这里有两个变化值得单独说说。
首先，联网搜索其实不是第一次开放，早在今年10月17日，DeepSeek就已经开放了自研Search和Fetch接口。
但当时，开发者还需要自己处理不少工具调用和模型之间的衔接工作。
比如用户问“最近AI圈发生了什么”，开发者需要先让模型判断要不要搜索，再调用Search找网页、用Fetch读取内容，最后把结果重新交给模型总结。
这一整套流程，都得开发者自己写代码串起来。
现在就简单多了。
开发者只要给模型打开联网搜索功能，什么时候搜索、搜什么、要读哪些网页，以及如何根据搜索结果继续回答，DeepSeek都会自动完成。
其次是语音，这次终于有了官方独立接口。
此前，DeepSeek App虽然已经支持语音交互，但公开的模型API并没有提供同样完整的语音能力。
开发者想做一个能听会说的DeepSeek助手，通常还需要另外接入语音识别、语音合成服务。
现在，ASR和TTS都可以通过DeepSeek官方接口调用了。
而且，上述底层能力也不必全部打包使用。
DeepSeek还提供了Search、Fetch、OCR、ASR、TTS等独立接口，开发者可以按需选择、自由组合。
目前，V4.1-Flash模型已在Messages、Responses和Chat Completions三类接口下支持相关对话扩展功能。
换句话说，D老师这次是把自家App背后的整套基础能力，像积木一样全部交到了开发者手里。
那么问题来了：
功能给得这么全，价格又如何？
语音识别一小时不到4毛，DeepSeek这次还打五折
先看DeepSeek这次公布的工具API价格表：
最扎眼的，当然是语音。
语音识别原价0.78元/小时，目前直接打五折，只要0.39元。
换算下来，一分钟大约0.0065元，识别一小时录音，连4毛钱都不到。
语音合成同样五折，原价每万字符3元，现在只要1.5元。
什么概念？
对比一下国外主流厂商的语音API价格：
OpenAI的GPT-Transcribe，识别一小时音频需要0.27美元
（约合人民币1.81元）
。
即便是更便宜的GPT-4o mini Transcribe，也要0.18美元
（约合人民币1.21元）
。
Google Cloud的标准语音识别服务，按0.016美元/分钟计算，一小时是0.96美元
（约合人民币6.43元）
。
相比之下，DeepSeek目前的0.39元，分别只有上述三款服务价格的约1/4.6、1/3.1和1/16.5。
至于搜索和网页抓取，依旧是此前公布的每1000次成功调用5元。
文字识别OCR则为每1000页1.5元，平均识别一页只要0.0015元。
这么一看，DeepSeek这次的定价思路也挺清楚。
原有的搜索能力保持低价，新开放的语音接口再用五折优惠降低使用门槛。
对于想做语音助手、会议记录、文档处理等应用的开发者来说，至少基础工具的调用成本，已经被压到了相当低的水平。
（D老师还是你D老师）
One More Thing
最后，还有个挺有意思的细节。
DeepSeek在公告末尾写道：
DeepSeek现有的对话产品只是较为基础的一种形态。
这话倒也符合D老师一贯以来的画风。
一直以来，相比花大力气经营C端产品，DeepSeek似乎更愿意把精力放在模型研发上。
DeepSeek App虽已积累了大量C端用户，但从产品形态上看，依然是大家熟悉的聊天助手。
如今，它干脆把所有能力全部开放，甚至连复刻自家APP的示例代码都准备好，颇有一种：
模型我继续研究，应用该怎么玩，就交给大家来摸索的意思
。
怎么说呢？这招还挺机智的。。。
回头看移动互联网时代，微信、抖音这些超级应用，几乎重塑了人们社交、娱乐乃至获取信息的方式。
而到了AI时代，大模型已经越来越强，应用形态却似乎还没跟上。
从ChatGPT到DeepSeek，大家最熟悉的交互方式，依然是打开一个聊天框，输入问题，等待回答。
但AI的下一款超级应用，真的还会是一个聊天框吗？
眼下谁也没有答案。
既然如此，与其自己关起门来猜，不如把工具都摆出来，让全世界的开发者一起试。
万一真有人折腾出了下一个爆款呢？
真就D老师大舞台，有脑洞你就来。（doge）
