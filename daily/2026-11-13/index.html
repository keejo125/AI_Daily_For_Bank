谷歌发布 Gemini 4 Hydrogen：面向日常编程与智能体任务的快速执行模型
Google DeepMindMarkTechPostTLDR AI智东西InfoQ
谷歌 DeepMind 于 11 月 12 日发布 Gemini 4 Hydrogen，定位为「日常智能体工作主力模型」，介于旗舰 Carbon 与深度推理 Argon 之下。默认 high 思考档在 Artificial Analysis 综合智能指数得 51 分（超 Argon 的 50），xhigh 档升至 54；任务执行速度达 Gemini 3.8 Flash 的 2.5 倍，Terminal-Bench 4.1 得分 57%（3.8 Flash 仅 18.2%）。模型仅经 API 与 Google 各产品入口提供，百万级统一上下文窗口，已接入 Google AI Studio、搜索与 Antigravity 等全档位，搜索侧称其为迄今最大一次模型升级。
Liquid AI 发布 LiquidCodec：7400 万参数流式语音编解码模型
MarkTechPost
Liquid AI 开源 LiquidCodec，即其 LFM3-Audio-2B 与 LFM3-Omni-2B 背后的语音编解码器，约 7400 万参数，将 24kHz 音频压缩为 12 路 token 流（每 80ms 帧生成 12 个离散 token）。单 CPU 线程即可约 361 倍实时编码，在 8 个测试集的 ViSQOL 与梅尔距离上均优于 X-Codec 2、NanoCodec 与 Mimi；权重已上 Hugging Face，并提供 CUDA 与 llama.cpp GGUF 构建，替换此前使用的 Kyutai Mimi。
AWS 发布 AWS Emulator：由 AI 智能体构建的本地 AWS API 模拟器
MarkTechPost
AWS 发布 AWS Emulator，一个本地运行的 AWS API 模拟器：在笔记本、开发服务器或 CI 中运行，CLI 与 SDK 改指向它即可，无需账号、无服务费。其特殊之处在于全部代码由自主智能体编写与审查，基于 438 个 AWS API 模型覆盖 200+ 服务；v1.0.322 通过 24243/42857 项保真测试（56.6%），KMS 最佳（93.9%）、CloudFormation 最弱（15.8%），为开发者与编码智能体提供快速免费的 AWS 形态测试回路。
CopilotKit 发布 OpenBot 1.0：可自托管的 MIT 许可 AI 同事
MarkTechPost
CopilotKit 于 11 月 9 日发布 OpenBot 1.0，一个 MIT 许可、可自托管的智能体工作区，反其道而行——企业自带模型、智能体与基础设施。每个 Bot 拥有独立容器（含专属浏览器、登录态与文件），仅触达被授予的工具；所有浏览器点击、文件写入、MCP 调用与组件都经由统一网关，先写审计行再执行，拒绝规则优先于允许规则，治理内置、动作可审。
Docker 呼吁通过隔离与治理保障智能体安全
InfoQ
Docker 发布指南，指出自主 AI 智能体在有限监督下浏览网页、运行代码、调用工具时存在五大安全风险：提示词注入、工具滥用与投毒、过度自主、凭证泄露与数据窃取。Docker 认为根因在于智能体可在运行时自选工具、串联操作并以启动者权限运行，主张以隔离与治理（而非仅靠模型约束）为防御主轴，并呼应 OWASP 智能体式 AI 威胁与缓解指南。
容器隔离还不够：Edera 从虚拟机监控器层限制 AI 智能体
InfoQ
Edera 推出对象能力受限权限模型，直接在虚拟机监控器层实施细粒度对象能力控制，使自主智能体与 MCP 服务器同敏感凭证隔离。核心是将完成任务所需权限与底层凭证分离：capcurl 实现无凭证 API 访问，capsudo 管理限定作用域的命令执行，并集成 SPIFFE/SPIRE 做密码学工作负载身份，将入侵影响从整个环境缩小到特定任务操作，初步功能已发布。
谷歌推出 LiteRT Tensor API，用于构建、定制与优化端侧机器学习模型
InfoQ
谷歌推出轻量级 C++ API LiteRT Tensor，让开发者用逐个算子的计算图直接面向端侧构建、定制与优化机器学习模型，同一份图可在 CPU/GPU/NPU 上运行而无需重写。支持直接导入 Hugging Face .safetensors 权重与零拷贝缓冲区互操作，并与 AI 编码智能体兼容——演示中智能体将 SAM 2 的逐帧决策移入计算图并重写触发 CPU 回退的操作，在 WebGPU 上 512×512 帧率从不足 10fps 升至 30fps 以上。
