# OpenAI连发两款GPT‑6新模型！API价格腰斩

来源：智东西
原文链接：https://mp.weixin.qq.com/s/1xNYXtYQ4ONDXM8rfr5d8Q

对齐评测均优于各自的GPT-5.6前代模型。
编译 |
杨京丽
编辑 |
李水青
智东西9月23日消息，今天凌晨，OpenAI发布GPT-6系列两款新模型
GPT-6 Sol和GPT-6 Luna
，已开放API，并开始向Plus、Pro、Business和Enterprise用户逐步推送至Codex和ChatGPT Work。
两款模型延续GPT-6 Astra的技术进展，
重点提升性价比
。OpenAI称，得益于缓存和推理效率的改进，Sol和Luna在提升智能水平的同时，
API价格较上一代GPT-5.6对应模型降低50%
。
按每百万token计费，GPT-6 Sol输入价格从上一代的4美元降至
2美元（约合人民币13.4元）
，输出价格从20美元降至
10美元（约合人民币66.9元）
，均下降50%。GPT-6 Luna的输入价格从0.20美元降至
0.10美元（约合人民币0.67元）
，输出价格从1.20美元降至
0.50美元（约合人民币3.35元）
。
GPT-6 Luna这一价格甚至比DeepSeek-V4.1-Flash的空闲时段价格还低。
目前，DeepSeek-V4.1-Flash每百万token的非缓存输入价格为空闲时段1元、高峰时段2元，输出价格分别为4元和8元。
编程方面，OpenAI称，在测试编程Agent长周期工程任务能力的DeepSWE v1.1上，GPT-6 Sol在max推理档位下得分为68.8%，仅比Claude Fable 5 xhigh档位下的69.9%低1.1个百分点，
单任务成本却低约80%
。GPT-6 Luna在max档位下，表现与medium档位的Claude Fable 5相当，Luna的单任务成本分别
比Opus 5和Fable 5低93%和96%
。
在衡量AI跨应用完成真实业务流程能力的AutomationBench上，OpenAI称，GPT-6 Sol在xhigh推理档位下的表现超过max档位的Claude Opus 5，单任务成本仅为后者的
9%
。在high推理档位下，GPT-6 Luna的得分较上一代
提高5.4个百分点
，单任务成本
降低58%
。
此次更新还改进了提示词缓存。当Agent调整推理强度或可用工具时，更多已有上下文可以继续复用，减少重复处理，从而缩短响应时间、降低使用成本。OpenAI称，两款模型延续了Astra在对齐方面的改进，在其对齐评测中优于各自的GPT-5.6前代模型。
