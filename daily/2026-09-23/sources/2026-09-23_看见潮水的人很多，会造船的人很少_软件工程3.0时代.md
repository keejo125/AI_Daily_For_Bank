# 看见潮水的人很多，会造船的人很少

来源：软件工程3.0时代
原文链接：https://mp.weixin.qq.com/s/909vZ1pCY2qyWIdWwL-J1Q

第11届AI+研发数字峰会（AiDD，深圳，2026.11.20-21）邀您同台执笔
主题
：AI引领研发，智创无限可能
官网：https://www.aidd.vip/2026sz
AI写代码，快约 6 倍。团队吞吐，只快约 1.3 倍。
这中间的落差，就是今天研发人真正的战场。
模型越强，被它遮住的问题反而越快浮出水面：需求有没有说清，边界谁来把关，结果谁来验收，经验能否沉淀，个人的巧劲能不能变成组织的本事。
看得见潮水，是常识；造得出船，才是本事。
AiDD
十届以来只做一件事——
帮国内的研发组织，把AI造进船里，而不是浮在水面上。
一、一个判断：不是"研发加 AI"，而是"AI重写研发"
两种做法，结果完全不同。
一种是
X
+AI
：给产品加个智能入口，给工具加个AI按钮。
X
还是主角，流程纹丝不动。一种是
AI
+X
：把AI当引擎与底座，需求、编码、质量、组织，全部重写一遍。
2023 年 4 月，当多数人还在争论"AI会不会抢饭碗"，AiDD就已明确提出：
软件研发将从"X+AI"转向"AI+X"：
AiDD峰会的定位、视野与未来
此后三年，行业每一步演进，都在为这个判断补上注脚。
方向对了，努力才有复利。
二、一种专注：只解一道题，并把它解到底
市面上的AI大会很多，有专注大模型技术，也有专注AI产品或应用的，大多在讲"AI能做什么"。但AiDD只回答一个问题：
AI如何重塑"软件研发"这件事本身
不讲泛泛的趋势，只讲
从需求到上线
的完整链路；
不追热词，只追
能落地、可复用、可度量
的工程答案；
15+
分论坛、
60+
创新案例，几乎
没有一场"跑题"的分享
。
有专注，才有专业
。这正是AiDD被称作"AI+研发"领域首选会议的原因——
不是因为最大，而是因为最专。
三、五条主线：你对号入座，答案各就各位
参会最怕议程一摞、却不知哪场属于自己。AiDD把选择成本降到最低——按"研发价值链 × 你的身份"划出
五条主线
：
每天和代码较劲的→ 「AI+开发」线：
Coding Agent Harness 与组织进化、Agentic 研发流程重塑、AI+工业软件开发。看编码智能体如何从"玩具"变成"同事"。
为质量夜不能寐
的→ 「AI+测试」线：
从AI辅助到自主测试、Testing Agent Harness 与测试平台、智能体评测与进化。从"AI帮你测"，到"AI自己测"，再到"凭什么信它测得对"。
守着合规与底线的→ 「AI+
质量闭环」线：
Harness 驱动的质量闭环、
OPPO专场：AI 赋能测试与质量体系创新实践
、SDD 落地实践与规约工程。AI落地最难的三道题，这里都有解。
带团队的效能与平台负责人→ 「AI+工程效能
」
线：
智能体工程与可观测性、AI驱动研发效能跃迁、本体论与知识工程。讲的是如何把"个人提效"升格为"组织产能"。
盯着海外与新赛道的→ 「AI+出海
」线：
AI赋能 SaaS 全球化、企业级 FDE 定位与培养、Agentic Harness 与海外产品。从中国AI走向全球，到下一代人机形态。
一句话：
从需求到上线，一环不缺；从个人到组织，一级不落。
四、一份底气：讲台之上，都是打过仗的人
真正的专业，不必高声。看两处细节即可。
第一处，论坛主席的名单。
写着这些名字：
邬超（OPPO）、黄胜鲁（中兴通讯）、安秋（金蝶）、王昊奋（同济大学·OpenKG）、马宇驰（华为云）、李华伟（阿里巴巴）、彭云鹏（百度）、李伟（西门子）、钱岭（中国移动）、罗慧（腾讯）、郭晓辉（平安人寿）
……
议题由产学研联合技术委员会把关出品。
大咖不是来"站台"的，是来"出品"的。
第二处，他们要讲的内容。
不讲"我用了什么模型"，只讲"我踩过哪些坑、怎么填平的"：
某央企：需求到开发启动，
从 5天压缩到 1天
；
去哪儿旅行：数百人团队
出码率长期75%以上
，并追问"出码率越高就越好吗"；
华为码道：AI生成占
40%—80%
，写码快 6倍，吞吐只快 1.3倍——
阻塞点究竟在哪？
中兴通讯ATDD端到端：成功率
从 43.84%提升至 66.67%
，用"真实验收"取代"用例生成率"；
58 同城：移动端测试
流程复用率 80%、任务完成率 93%
，覆盖 4个BG、11个项目、379条核心链路；
某互联网公司：AI自主生成代码约65%，
变更失败率却提升了30%
——提速之后，质量怎么跟上？
这些数字最能说明AI价值所在、问题所在，最值得我们去学习和探究。因为它们讲的不是"AI很行"，而是"
AI想真正行，还需要什么
"。
截至目前，已提交的议题来自腾讯、蚂蚁、科大讯飞、美团、支付宝、荣耀、广联达、用友、网龙、微众银行、平安等一流企业——
深圳这一站，讲师正在汇聚。
五、一封邀约：这一届，想请您上台
如果您手上有这样的东西，AiDD深圳站就是它该出现的地方：
讲得清链路
——PRD 如何走向 Specs，意图如何变成契约；

我们看重的不是"讲趋势"，而是
讲交付

这样能做成
"。

一套方法论
——Harness 怎么搭、质量怎么守、评测怎么做、人才怎么养；
一张路线图

一群同路人
——1200+ 同处转型期的工程师、管理者与决策者。有些问题，只有同路人才懂。
模型决定能力上限，工程决定能力能否留下。
两天之后，您带走的不是一摞笔记，而是一条能走下去的路。
