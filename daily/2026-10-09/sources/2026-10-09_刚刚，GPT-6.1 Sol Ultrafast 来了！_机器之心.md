# 刚刚，GPT-6.1 Sol Ultrafast 来了！

来源：机器之心
原文链接：https://mp.weixin.qq.com/s/qe3dJ1yVFGaLpzmk_-9gEA

编辑｜冷猫
今天是 Tibo 大神「连续 28 天发布或重置」的第四天，重磅的来了！
昨天，OpenAI 决定向所有用户（包括免费和付费用户）开放 GPT-6 ，今天就推出了全新的模型
GPT-6.1 Sol 的 Ultrafast 版本
！结合更新的模型控制系统，能够实现对用户指令调整的及时响应。
涡轮增压
GPT-6.1 Sol 本身在 9 月 29 日的 DevDay 上刚发布，定位是「接近 Astra 的能力，五分之一的价格」。标准版 API 定价是每百万输入 token 2 美元、输出 10 美元，已经是目前性价比最高的前沿模型之一。
Ultrafast 模式在这个基础上把速度直接飙升到了 8 倍。
OpenAI 称其为「Near-Astra intelligence at up to 8x faster speeds than Sol Standard」。翻译一下就是：智能水平和标准版一致，依然逼近旗舰 Astra，但速度翻了 8 倍。
这也是 OpenAI 在「Ultrafast」概念上的第二次迭代。今年早些时候，他们曾与 Cerebras 合作推出过 GPT-5.6 Sol 的 Ultrafast 预览版，当时宣称输出速度高达 750 tokens/s，是标准速度的 14 倍。GPT-6.1 Sol Ultrafast 的 8 倍提速幅度看起来保守了一些，但考虑到 6.1 Sol 本身的智能水平已大幅超越 5.6 Sol，能在更高的能力基线上做到 8 倍加速，含金量其实更高。
这种速度对开发场景的意义是毋庸置疑的。OpenAI 给出的典型用例包括：线上故障排查、智能体实时导航应用、以及任何「每一秒都在烧钱」的实时交互场景。
API 定价方面，
Ultrafast 模式是每百万输入 token 12 美元、输出 60 美元
，恰好是标准版的 6 倍。
OpenAI 开发者关系工程师 Dominik Kundel 给了一个更直观的定位：
「接近 Astra 级别的智能，8 倍于 Sol 的速度，成本仅为 Astra 的 1.2 倍。」
拿 Astra 的标准 API 价格（每百万输入 10 美元、输出 50 美元）做对比的话，Ultrafast 确实只贵了一点点，但换来了远超 Astra 的响应速度。如果你的业务场景里 Astra 的速度不够用，Ultrafast 提供了一个「加一点钱买一堆速度」的选项。
Ultrafast 的能力参数很诱人，但有一个关键信息几乎被淹没在了公告里。
在 Codex 和 ChatGPT Work 端，
Ultrafast 仅对 Pro 500 订阅用户、符合条件的按量付费 Enterprise 用户和 Edu 用户开放。
Pro 500 是 OpenAI 今年推出的月费 500 美元的高端订阅计划。这意味着对于普通 ChatGPT Plus（20 美元 / 月）甚至 Pro（200 美元 / 月）用户来说，想在 ChatGPT 或 Codex 里用上 Ultrafast，还得再加钱。这就引发了用户们的不满情绪。
有开发者试用后表示，Ultrafast 在 XHigh effort 模式下确实快得惊人，但 token 消耗速度也同样惊人，
500 美元月费对应的 25 倍用量额度在这种模式下「几分钟就能烧掉 1%」
。也有人质疑限制逻辑本身：「如果 Ultrafast 会更快地消耗我的用量额度，那为什么不让所有付费用户自己选择？我愿意承受更快用完额度的代价。」
当然，API 端不受订阅等级限制，开发者可以直接调用 gpt-6.1-sol 模型并启用 Ultrafast 模式，按量付费即可。这对搭建智能体、做实时应用的团队来说门槛并不高。
GPT-6.1 Sol Ultrafast 的即时价值在于：它在 API 层面提供了一个「接近旗舰智能 + 极致速度」的组合，且不需要等 Astra 降价。对于普通用户来说，即时响应带来的体验提升或许更直接，毕竟没有人喜欢眼睁睁看着模型往错误方向一路狂奔。
