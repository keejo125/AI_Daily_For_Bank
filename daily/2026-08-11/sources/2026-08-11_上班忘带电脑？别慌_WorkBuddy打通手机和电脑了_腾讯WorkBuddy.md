# 上班忘带电脑？别慌，WorkBuddy打通手机和电脑了

来源：腾讯WorkBuddy
原文链接：https://mp.weixin.qq.com/s/XKDwvBBnSvhcXdHGSZPNPQ

Buddy 们，WorkBuddy「多端同步」来了！
✅移动和PC端打通
✅任务和产物多端同步
✅远程遥控电脑
WorkBuddy 真正突破设备边界，
实现了 PC、APP、小程序三端的任务、对话记录与产物的实时同步，支持手机上远程对电脑端任务进行授权与停止。
随时随地在线，跨设备切换不再打断工作流。
怎么用？
登录同一账号即可同步
移动端和桌面端登录相同的账号即可，不用扫码、不用配对、不用手动授权——账号一致，就会默认打开桌面端「允许移动端连接」的开关，任务和工作空间就自动同步过来。
（APP需升级到 1.2.0 及以上版本、PC端需升级到 5.3.8及以上版本）。
（PC端开关）
设备区域展示「绿色圆点」 = 状态链接中+ Agent 在工作，无需回工位，就能了解任务状态。
（移动端显示）
手机远程同步控制电脑，
Agent 接着跑
以前，一旦离开工位，Agent 在电脑上干什么，就成了一个黑盒。
● 设备是什么状态？
● 任务跑完了吗？
● 需不需要我确认？
现在，点进任意一个对话，就能看到 Agent 当前正在读哪些文件、下一步要做什么，并且远程遥控电脑上的任务授权与操作。
跨项目切换：
任务、工作空间与桌面一致
同时跑几个项目的 Buddy 应该深有感触：电脑上开着 A 项目、B 项目、C 项目，Agent 在各个工作空间里干活，互不干扰。多端同步把这个结构原封不动搬到了手机上，
现在，打开手机 WorkBuddy，桌面端的任务列表和工作空间结构完全一致
——「任务」+「工作空间」双分组并列展示，重要任务不会「消失」。
手机上按工作空间分组查看，
点进任意一个空间，就能看到这个项目下的所有对话。切换项目不用退出，不同项目的任务列表不会串扰。「开会前看一眼A项目跑到哪了、休息时点进 B 项目回一句话续聊、回工位后 C 项目的产物已经在等你」——
多线并行的节奏，不再被工位束缚。
双端联动：
手机、电脑协同工作
多端同步不只是「远程操控」，也是「协作完成」。
手机拍一张发票、传一份文档，电脑端的 Agent 就能识别内容、分类归档、录入表格——
手机负责采集，电脑负责处理，中间不用来回传文件。
● 出差回来，路上把发票拍好，Agent 到公司已经录完；
● 现场看到一份材料，手机拍一下，电脑立刻结构化提取；
● 想到一个想法，手机语音输入，电脑接过去继续展开成文档。
手机是眼睛和耳朵，电脑是大脑和双手，无缝接力完成任务。
多设备切换：
一台手机，连接多台电脑
一台手机可以连接多台电脑，切换设备就能分别拉不同设备上的任务、工作空间列表。
在公司让 Agent 跑一个任务，晚上回家想继续跟进对话？设备点击公司电脑，任务和对话原样展示，丝滑开工。
想要家里那台电脑上的文件？点击切换设备到家用电脑，直接可以发送指令接收到家用电脑文件。
不同设备的 AI 工作台，一部手机全部串起来。
锁屏也可办公：
电脑锁屏 Agent 依旧开工
「打开着 APP 才能远程」是很多远程工具的软肋——电脑一进入休眠模式，连接就断了、任务就停了。
WorkBuddy 多端同步支持「锁屏远程」：在桌面端打开「允许锁屏远程」开关，开启后：
● 电脑不会自动进入休眠
● 屏幕也不会自动关闭
● 手机锁屏状态下，依然可以远程操控
不用一直亮着屏幕盯着，也不用担心中途断连
—— Agent 该跑就跑，人该干嘛干嘛。
任务远程急停：
跑偏了？远程立刻止损
Agent 开始执行后，你可能又有了新想法：想补充要求、调整方向，或者换一种处理方式。以前，人不在电脑前，只能等当前任务执行结束，再回来重新安排。
现在，在对话运行中点「停止」，即可终止电脑端 Agent 的当前执行。
修改指令后，随时可以重新出发，
让每一份 Token 都不被浪费
。
任务停在哪一步、已经产出了什么、接下来如何调整，都会完整留痕。思路有变化，也能随时接手、灵活调整。
