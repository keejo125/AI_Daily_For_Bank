从 Harness 到 Loop：真正决定 Agent 落地的，从来不是更强的模型
InfoQ
InfoQ《极客有约》× QCon 邀请蚂蚁、腾讯、京东专家，探讨 Agent 在生产环境的自进化。核心观点：Harness 解决「Agent 怎么把任务完成」（静态系统），Loop 解决「怎么越变越强」（进化系统）；模型能力不等于系统能力，工程化体系决定交付下限；Loop 能自动化执行，但决策与验收仍须人拍板，最大缺口是 Agent 缺乏人的上下文。
