# 从Agent自评到量化数据验证：华为云码道Skill自进化技术探索与实践

来源：CSDN
原文链接：https://mp.weixin.qq.com/s/8oWaUsf03xGPaHK2dRmlXQ

面对反复出现的开发任务，开发者可以将要求写成 Skill，但传统编写方式常缺少量化评测数据：哪些要求真正被满足、下一版该改哪里，都不够清楚。码道构建了“意图识别 → 评测集生成 → Skill 编写 → A/B 测试 → 轨迹分析”的演化循环，用量化结果和执行反馈为下一轮 Skill 编写提供方向；同时从用户与智能体的任务轨迹中提炼经验，在交互过程中生成可复用的 Skill。
背景、问题及挑战
设想一个团队每天都在新增接口、补充测试和修复缺陷的项目，智能体已经能够参与这些工作，但在持续使用中遇到了三个问题。
第一，要求明确，却需要每次重新解释。
例如，为接口补充测试时，开发者总要提醒智能体：不仅验证成功响应，还要检查鉴权、非法参数、重复提交和状态转换。单次对话中的要求容易随着会话结束而失去作用。
第二，已有方法仍会遗漏细节，工作时演化可能争用模型资源。
团队已经有一份接口测试 Skill，但遇到重复提交或订单状态变化时，仍可能只断言响应码，没有检查数据和副作用。开发者希望先明确评测要求，再让系统在空闲时间自动演化，减少对工作时模型调用的影响。
第三，有价值的经验藏在执行过程中。
智能体修复问题时，可能发现一个不明显的构建顺序，或者通过多次排查找到稳定的测试隔离方式。如果没有主动整理，这些经验很容易留在历史聊天中，下次再遇到类似任务仍需重新探索。
三个问题对应三种使用需求：
目标明确时，用评测结果指引 Skill 生成；日常开发时，从真实任务轨迹提炼经验；已有 Skill 和评测任务时，利用空闲时间自动演化。
码道的 Skill 自进化能力为这三种需求提供不同入口，让能力建设、经验沉淀与闲时优化形成连续过程。
码道Skill自进化技术方案
2.1 评测驱动的 Skill 演化闭环
码道的Skill自进化能力为每个 Skill 准备了一个物理演化空间，集中保存评测集、分版本的 Skill，以及每一次AB测试时对应的轨迹分析结果与版本证据。当用户有明确目标时，Skill自进化会依据用户输入的目标编写评测集，生成候选 Skill，通过当前评测集上的实际测试决定该Skill是否有效，据此决定取舍与下一轮改进方向，如图 1 所示。该能力还会在用户会话空闲时自动进化演化空间中的Skill，达到合理利用用户空闲时间，让Skill的能力不断变强的目的。

2.2 基于任务轨迹的 Skill 生成
除此之外，码道的Skill自进化能力还能从用户与智能体的实际交互中发现经验。如图 2，插件在交互过程中持续监听工具调用与助手轮次，积累任务轨迹；择时触发隔离工作区中的分析与 Skill 生成。该能力旨在从用户真实解决任务的实践中提取高价值的复用模式，并且沉淀为Skill。
图 2：交互中监听任务轨迹并分析生成 Skill
码道Skill自进化案例
假设你是一个维护订单服务的团队，团队既要为下单、取消订单接口补齐测试，也要处理共享包导出引发的构建问题。
3.1 先明确目标，生成有评测依据的 Skill
开发者希望以后让智能体为订单接口写测试时，除了成功响应，还能检查鉴权、非法数量、相同幂等键重复提交、订单状态与库存副作用。在订单项目的码道会话中，可以把任务目标和验收条件一起交给前台入口：
/skill-evolver 为当前项目创建接口测试 Skill，沿用项目现有测试方式，并运行相关测试。
系统将要求转成评测集，编写候选 Skill，并通过 A/B 测试比较基线与候选在这些任务上的表现。开发者可通过/skill-log 命令查看 Skill 内容和相应的演化依据，确认它要求检查关键数据与副作用，且验收结论来自实际执行，而不只是文字描述。
最终生成的结果将会直接推送到码道的Skills下面，可直接被智能体在后续的工作中检索并且使用。
3.2 白天正常开发，从交互轨迹沉淀新方法
订单服务团队正在当前分支补齐接口测试时，临时需要拉取发布分支排查共享包导出导致的构建问题，又不希望打断现有开发现场。团队因此希望通过 Git Worktree 在当前工作区旁快速创建独立目录，并沉淀为可复用的标准操作。
如果想让对应的Skill记住这个能力，无需另行提交“生成 Skill”的命令。码道的Skill自进化能力会复盘用户解决问题的过程，并自行在后台生成对应的Skill。
3.3 用户空闲后，让已有 Skill 继续演化
接口测试 Skill 已有评测集，便具备后台演化的基础。开发者可以在结束当天的工作时启动指定 Skill 的后台任务：
/skill-evolver-auto
守护进程会自动执行该Skill的持续演化。下一次打开项目时，开发者可查收持续演化后的技能，并通过 /skill-log指令查看该技能的演化日志。
总结与展望
码道的Skill自进化能力分囊括了用户开发过程中的常见场景，无论是目标明确的能力建设、或日常执行中发现和保存可复用方法，都可以使用该能力让开发经验能够被保存、再次使用，并逐步接受验证。
