# 文心 5.5 Flash Preview发布！

来源：百度AI
原文链接：https://mp.weixin.qq.com/s/w1xzkKGQdtd7KNJjS7SAyQ

今日，
百度最新基础模型文心 5.5 Flash Preview正式发布
。总参数量达 2800 亿，每个 Token 激活 140 亿参数，支持最长 100 万 Token 的上下文，
在编程、3D 建模、知识工作、内容创作等方面表现突出。
01.
多项测试领先
每秒200 tokens 的模型有多丝滑？
文心 5.5 Flash Preview
目前在Terminal-Bench、AutomationBench等多项基准测试中，
取得了具有竞争力的得分，并保持极致的解码速度。
在底层技术上，文心 5.5 Flash Preview通过全新的混合稀疏注意力架构、多路由器 MoE、ECHO 多 Token 预测等多项技术创新，提升模型能力的同时降低计算和显存开销，
支持百万Token长上下文，实现每秒超过200 tokens的生成速度。
此外，文心 5.5 Flash Preview首次引入自研的RSI技术，
由ERNIE Evolve参与模型推理优化
，探索AI参与模型研究与优化的新路径。
02.
挑战长周期复杂任务
兼顾智能水平和推理效率
▎游戏开发
编程能力又上新台阶
。
文心5.5 Flash Preview 覆盖从真实代码库中修复迭代，到完整构建复杂应用的广泛编码场景。
尤其在长周期的开发任务中，模型展现出更强的规划、执行与持续迭代能力，这也大幅提升了文心 5.5 Flash Preview 的游戏开发效果。
模型针对游戏开发场景进行了专项训练，并适配主流开发工具，根据用户的创意和需求，完成游戏设计、功能制作和场景搭建，让用户更便捷地将游戏创意变成可体验的作品。
基于 Cocos、Unity、LayaAir、PixiJS、Canvas 2D，文心 5.5 Flash Preview 根据完整的游戏策划方案做出近百款手机小游戏，玩法、内容、美术和音效齐全，覆盖弹幕射击、肉鸽、塔防、竞速、卡牌 RPG、城建经营、物理解谜和互动叙事等品类。
▎3D建模与设计
文心 5.5 Flash Preview
在参数化建模和空间推理方面尤为出色。
通过加强模型对 Blender 和 CAD 等工具软件使用的专项训练，显著提升了模型的3D建模与设计能力。
借助工具辅助，文心 5.5 Flash Preview能够从文本描述中准确理解并推断物体的形状、比例及空间关系，通过程序化建模将其转化为精准的3D模型。同时，能够灵活整合与复用现有资产，将外部素材统一集成到现有工作流，创建出场景宏大、细节丰富的 3D 场景。
两个由文心 5.5 Flash Preview 驱动的 Agent 用 Blender Python API 制作：
机场部分，
模型自己从地图平台检索布局矢量数据，按需下载植物、车辆和地面服务设备等辅助素材，用参数化建模搭建航站楼和飞行区。
飞机部分，
模型用截面放样和模块化装配做出机身和机翼，再用预先提供的生成素材装配驾驶舱、双层客舱和货舱。
整个项目像真实工作一样拆成子任务，各自推进又相互配合。
▎专业知识工作
在专业知识工作和内容创作领域，文心 5.5 Flash Preview 能够根据用户需求完成多步工作，
交付高专业度的表格、文档或演示文稿
。模型在后训练中，已面向金融、法律等领域，构建了 30 万个工作空间、1000 万份参考文件，覆盖 40 多种文件类型，训练环境覆盖从 10 到 100 个文件的个人工作空间，以及上千个文件构成的企业知识库。
文心 5.5 Flash Preview 聚焦 2026 年自动驾驶行业发展，独立完成了一份 24 页的专业研究报告，系统对比 Waymo 无人驾驶 Robotaxi 与 Tesla 监督式 FSD 在安全表现、商业化进展及数据透明度方面的差异。
模型通过数据清洗、事件去重、趋势分析与多维交叉验证，揭示两种自动驾驶技术路线在安全表现及数据披露机制上的关键差异。在多源信息整合、复杂数据分析、专业研究报告交付等表现优异。
▎视频创作
面向内容创作者的视频创作需求，
文心 5.5 Flash Preview 能够搜集、合成和编排素材，调整画面和节奏，输出成片。
模型已
面向科普、漫剧、创意剪辑、热点演绎等场景构建了超过 15 万个创作环境，覆盖创意生成、剧本、分镜、视觉素材和配音的完整流程，适配上千个创作 skill，累计成片约 5300 分钟。
从完全用代码渲染的微缩世界，到调用视频生成模型呈现的神话史诗，风格各异的作品接连亮相，背后的剧本、分镜与合成都由文心 5.5 Flash Preview完成。
它能通过代码和工具把想法组织成故事。代码能力让画面合成落地，长程 Agent 能力则持续推进复杂任务。
制作过程中，文心 5.5 Flash Preview 连续工作一到两个小时，工具调用中位数约 170 次，自己检查结果、发现问题并修正，让从一句话到一条视频的过程形成完整闭环。
目前，文心 5.5 Flash Preview已上线百度智能云千帆平台，开发者可通过API调用模型。API定价为每百万Token输入忙时2元、闲时1元，输出忙时8元、闲时4元，限时五折，在同参数规模模型中具备较强价格竞争力。此外，模型权重将于11月25日正式面向全球开源社区发布。
