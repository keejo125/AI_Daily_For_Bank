# Qoder Voice 全新发布，国内首个实时语音交互智能体

> 原文链接：https://mp.weixin.qq.com/s/v8dKt6vdoHvwiVCeLhItAw
> 公众号：Qoder

Qoder Voice 全面升级，支持全双工实时语音交互，常驻聊天气泡可在任意位置唤起。

从今天起，你和 Qoder 之间的协作方式，从一来一回的"笔谈"，变成随时开口的"共事"。

一个真正的同事：能交流，也能干活

回想一下，和一个默契的同事共事是什么感觉：你的想法不用写成完整的文档，说个大概他就能动手；他干着干着，你随口一句"等等，先别提交"，他停得下来；他卡住了会转头问你一句，而不是闷头耗一下午；你们讨论方案，他能接住你的话，还会提醒你"这里有坑"。

这些人和人之间稀松平常的默契，放到人和 AI 之间，过去很难得到。大多时候，你只能把想法攒成一段完整的指令发过去，然后，等。

Qoder Voice 把这份体验搬到了人与 Agent的协作。

Qoder Voice 采用 Qwen-Audio-3.0-Realtime，一个“又快又聪明”的实时语音模型：毫秒级响应，压低时延却不掉“智商”，你随口、口语化的说法它能轻松Get。轻量的工具调用和上下文处理，在对话里当场就能完成。所以你说到一半改主意，它跟着拐弯；发现方案里有坑，会插话提醒。更复杂的活，交给 Qoder 完整的 Agent 能力。

你能感受到的就是，它一边和你讨论，一边把活干了：写代码、执行任务、操作浏览器和应用、通过 MCP 连接你工作中的各种系统。你看着它干，随口可以调整：

"不对，是第二个标签页。"

"这一步先别点，先把数据存下来。"

就像和你合作多年的老同事，事事有响应，件件能落地。

住在桌面的同事，随时都在

Qoder Voice 以一个桌面气泡的形式常驻在你的屏幕上。Qoder 客户端最小化了？不影响。你在写文档、开会议、看网页？随时可以开口派活，它也随时可能找你。

举一个程序员群体最真实的场景：在逛技术社区，刷到一篇不错的文章，里面的方案似乎正好能治你们项目里的一个老毛病。你只需要随口一句："看一下这篇文章里技术能不能用到我们项目。"

你接着往下刷，Qoder Voice已经开始读文章、翻你们的代码。几分钟后它开口："思路能用，我在测试分支里试了一版，跑通了，你要看看吗？"

那些"将来有空再研究"的念头，第一次有了当天的下文。

对话不依附于某个窗口。你在电脑上的任何地方，它都在。

写在最后

发布 Qoder Voice 的过程中，我们越来越确信一个判断：

IDE 也好，协作平台也好，正在慢慢变成 Agent 的工作台。代码在那里被编写，任务在那里被执行，但人类停留在工作台前的时间，会越来越短。

人保留的界面，也许会慢慢收敛成一个对话的入口。
