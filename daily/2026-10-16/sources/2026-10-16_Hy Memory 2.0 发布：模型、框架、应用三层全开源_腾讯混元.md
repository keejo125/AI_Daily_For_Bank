# Hy Memory 2.0 发布：模型、框架、应用三层全开源

来源：腾讯混元
原文链接：https://mp.weixin.qq.com/s/TT70I3zzMSLAae5LSPeMzQ

10 月 16 日，腾讯混元宣布智能体记忆框架 Hy Memory 升级到 2.0 版本，并开源专用模型、记忆框架和 MemHub 应用，三层能力既能独立使用，也能组合成一套完整的 Memory 解决方案，打造私人记忆管家。
图 1 · Hy Memory 2.0 三层开源架构
Hy Memory 框架
负责聊天、工作、代码三类记忆的存储、更新与进化，开发者可通过 SDK 将其接入 Agent；在覆盖聊天、工作、代码场景的 4 个 Benchmark 上均为开源记忆框架第一名。
Hy-Memory-30A3B 模型
专为记忆场景训练，具备很强的记忆更新、管理等能力，在多个主流记忆框架（Hy Memory、Mem0、MemOS等）上效果均超过 Opus5。
MemHub 是本地记忆管理应用
，CLI 和 Mac端 APP 均可使用，可
连接 WorkBuddy、Cursor、Codex 等 10 种 AI 工具，内置 Hy Memory SDK，提供历史记忆导入、跨工具实时记忆同步功能。在 AI 时代，无论技术如何演进，属于每个人的记忆应当始终完整、连续。使用 MemHub，让“
对话常新，默契常在
”。
图 2 · Hy Memory 2.0 使用方式
目前，Hy Memory 已在腾讯内部金融、资讯、知识管理、办公 Agent、社交娱乐和游戏等领域的多个
业务中使用。
腾讯自选股 AI 助手中使用 Hy Memory 后，多跳召回率从 50% 升至 90%，综合得分提升 23.8%，整体通过率从 64% 升至 81%；腾讯新闻在智声、新闻妹两个 AI 助手场景的长期偏好评测中，平均得分 91.68，其中 87.8% 的案例超过 90 分；iWiki 仅用 Hy Memory 召回的记忆作答，正确率比提供全部原始对话相对提升 48.6%。
从 1.0 到 2.0：聊天记忆升级，新增工作记忆与代码记忆
聊天记忆，从零散事实升级为完整的事件脉络。
当遇到
跨时间、跨对话的聊天场景时，Hy Memory 2.0 能够把分散的内容关联整理，以事件为主体梳理出时间、地点、人物等关键要素，并关联事件的后续发展。当遇到一个问题需要结合多条线索才能回答时，Hy Memory 会围绕问题整理相关内容，先合并重复信息、剥离前后冲突，然后再把清晰的记忆交给模型。
新增工作记忆与代码记忆。针对工作和代码场景，Hy Memory 2.0 使用多个维度记忆一项任务，并
按时间规整所有信息更新。其中包含：
任务目标、已确定的做法和阶段结果
可复用的经验、经验适用条件等
当复用过往经验时，Hy Memory 会先判断当前是否符合该条经验的适用条件，只在符合的情况下，精准采取对应经验作为辅助。针对长程任务，每次继续开启任务前，Hy Memory 会先判断当前在处理哪一件事，再找回相关决定、仍然适用的经验以及历史工作过程。从而精准获取最相关的记忆、辅助任务执行。

三类记忆场景占用很少存储空间，效果达到开源框架第一

工作记忆。
在 MemoryArena 的旅行规划与组合购物任务上，平均分为 55.31%，领先次优的 EverOS 10.2 个百分点。

图 10 · Hy-Memory-30A3B 跨四套记忆系统评测结果
10 种 AI 工具，共享一份个人记忆
用户逐渐在日常中同时使用多个 AI 工具，记忆也随之分散在不同场景。在 Cursor 中交代过的偏好，Codex 并不知道；在 OpenCode 中定下的规范，到了 WorkBuddy 又要重新说明。每切换一次工具，上下文就要从头补齐。
MemHub 希望让
记忆成为用户的长期资产，不应被任何单一工具限定，
让每次开口，都从懂你开始。
所以 MemHub
把不同工具中的会话汇聚成全局的个人记忆，并持续更新。用户无需改变使用习惯，也无需切换正在使用的工具，只需要在MemHub 中授权关联应用，即可导入各工具的历史会话，并通过内置的 Hy Memory SDK 沉淀为本地记忆。此后，各工具中产生的新会话都可实时同步，汇入同一份记忆。同时，MemHub 还支持以插件形式一键接入各个 AI 工具：用户在任何一个已关联工具内发起任务，MemHub 都可管理和使用相关记忆，作为上下文补充给当前工具。
目前已覆盖 WorkBuddy、Cursor、Codex、Pi、Qwen Code、Hermes、DeepSeek Harness 和 OpenCode 等 10 种 AI 工具，涵盖商业编程工具、开源 Agent。
已接入腾讯多个业务，专项评测表现出色
目前，Hy Memory 已接入腾讯自选股、iWiki、腾讯新闻等多个业务。在各业务的专项评测中，Hy Memory 显著提升了记忆召回与回答的准确性，让 AI 助手更好地理解并延续用户的长期偏好。
腾讯自选股：
多跳召回提升 40 个百分点。
自选股 AI 助手需要跨天、跨会话记住用户主动
提供
的关注方向、分析习惯和规则，例如“这周只盯有色和半导体”“分析先报 PE 历史百分位”。在 A 股投研记忆专项评测中，接入 Hy Memory 后，综合得分从 64.3 提升至 79.6，整体通过率从 64% 提升至 81%，多跳召回从 50% 提升至 90%，冲突消解从 67% 提升至 83%。用户调整关注方向后，旧方向归档但可追溯，助手不会再把已放弃的板块推回来。
图 11 · 腾讯业务专项评测结果
iWiki：
只用记忆，回答正确率高于完整原文。
iWiki 基于 Hy Memory 推出 CTX 记忆插件，让多个 Agent 共享同一份长期记忆。在 251 道问题的评测中，使用同一模型和同一套提示词，只提供 Hy Memory 检索出的记忆，正确率为 36.7%；提供全部原始对话，正确率为 24.7%，相对提升 48.6%。
腾讯新闻：
长期偏好理解评测平均 91.68 分。
腾讯新闻将 Hy Memory 引入智声、新闻妹两个 AI 助手场景。AI 能记住用户关注的话题和偏好的称呼，开场时主动提及用户关心的内容，多轮对话中延续上次聊过的话题。在智声场景的离线评测中，10 位用户的 41 个复杂对话案例平均得分 91.68（满分 100），87.8% 的案例得分在 90 分以上。
除金融、知识管理与资讯外，Hy Memory 也已在办公 Agent、社交娱乐和游戏等领域的业务中完成接入与评测。
接下来，腾讯混元将继续和更多业务深度协同，在真实场景中打磨记忆能力，让 Agent 在更长的任务、更多的工具之间保持连续。
