# AI能做不代表AI应该做！比尔·盖茨：有些位置必须留给人，必须为人类工作划“保护区”

来源：51CTO技术栈
原文链接：https://mp.weixin.qq.com/s/WnhT4GSSxHW_Z3GMM_5pCg

<p style="margin:0 0 8px;line-height:1.8">编辑 | 姜篇</p>
<p style="margin:0 0 8px;line-height:1.8">“Many jobs will disappear forever.”</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨：许多工作会永久消失。</p>
<p style="margin:0 0 8px;line-height:1.8">过去几年，比尔盖茨谈</p>
<p style="margin:0 0 8px;line-height:1.8">AI时总会提到新药、教育和生产力。</p>
<p style="margin:0 0 8px;line-height:1.8">这一次，他把失业、权力集中、生物安全和“人还要不要继续工作”摆到了前面。</p>
<p style="margin:0 0 8px;line-height:1.8">他甚至承认：</p>
<p style="margin:0 0 8px;line-height:1.8">如果处理不慎，AI带来的负面影响可能超过正面价值。</p>
<p style="margin:0 0 8px;line-height:1.8">问题也因此变得清晰具体了。</p>
<p style="margin:0 0 8px;line-height:1.8">公司当然会把能自动化的工作交给</p>
<p style="margin:0 0 8px;line-height:1.8">AI，成本更低，速度更快，还不用等人排期。</p>
<p style="margin:0 0 8px;line-height:1.8">可当AI能够完成一项工作，企业是否就该把人完全替换？</p>
<p style="margin:0 0 8px;line-height:1.8">如果处理不慎，AI的负面影响可能超过正面价值</p>
<p style="margin:0 0 8px;line-height:1.8">AI能做，不等于AI应该做</p>
<p style="margin:0 0 8px;line-height:1.8">企业引入AI，通常先算成本。</p>
<p style="margin:0 0 8px;line-height:1.8">一项任务原来需要工程师半天，现在Agent十分钟就能交出修改。依赖升级、接口迁移和测试补齐，也可以同时放到后台运行。</p>
<p style="margin:0 0 8px;line-height:1.8">只看效率，让AI继续接管工作似乎没有停下来的理由。</p>
<p style="margin:0 0 8px;line-height:1.8">Bill Gates在长文中举了一个医疗场景：机器人完全可以把“你患上了无法治愈的疾病”这个消息告诉病人。技术上没有障碍，但他紧接着写道：</p>
<p style="margin:0 0 8px;line-height:1.8">“Yet it shouldn’t.”</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨：但它不应该这样做。</p>
<p style="margin:0 0 8px;line-height:1.8">问题不在机器会不会说出这句话，而在于有些决定涉及痛苦、信任和责任，不能只交给一套追求效率的系统。</p>
<p style="margin:0 0 8px;line-height:1.8">这次技术革命为什么和过去不一样</p>
<p style="margin:0 0 8px;line-height:1.8">“This time really is different.”</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨：这一次真的不同。</p>
<p style="margin:0 0 8px;line-height:1.8">个人电脑普及用了很长时间。</p>
<p style="margin:0 0 8px;line-height:1.8">企业要买硬件、装软件、培训员工，旧流程才会一点点被替换。</p>
<p style="margin:0 0 8px;line-height:1.8">AI省掉了不少中间步骤。</p>
<p style="margin:0 0 8px;line-height:1.8">它能直接运行在现有电脑和手机上，人用自然语言就能下达任务。它还能读文档、看历史工单，甚至从培训视频里学习一项工作原来怎么完成。</p>
<p style="margin:0 0 8px;line-height:1.8">放进开发团队里，这种差别更明显。</p>
<p style="margin:0 0 8px;line-height:1.8">过去引入一套新工具，需要工程师学习命令、配置流水线、改造项目。现在的</p>
<p style="margin:0 0 8px;line-height:1.8">Agent会自己搜索仓库，调用终端，根据报错继续修改。工具适应人的速度，第一次可能快过了人适应工具的速度。</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨因此判断，AI对认知工作的冲击会来得更快。</p>
<p style="margin:0 0 8px;line-height:1.8">AI带来的挑战并没有遥远到可以再等几代人</p>
<p style="margin:0 0 8px;line-height:1.8">哪些工作需要保留人的位置</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨在文中提出了一个词：</p>
<p style="margin:0 0 8px;line-height:1.8">“Human Reserved”</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨：为人保留。</p>
<p style="margin:0 0 8px;line-height:1.8">他的父亲患阿尔茨海默病后，照护者不只是按流程完成任务。</p>
<p style="margin:0 0 8px;line-height:1.8">他们会陪伴、安慰，也会在病人说不清需求时作出判断。即使未来的机器能把这些步骤做得更快，比尔盖茨</p>
<p style="margin:0 0 8px;line-height:1.8">仍希望照护工作里保留人的位置。</p>
<p style="margin:0 0 8px;line-height:1.8">放到软件开发里，没必要要求每一行代码都由人亲手写。该留下的是几个关键节点。</p>
<p style="margin:0 0 8px;line-height:1.8">需求是否值得做，不能只看工单描述；一次改动能承受多大风险，不能只看测试通过率；生产权限交到哪里，出了事故由谁叫停，也不能由</p>
<p style="margin:0 0 8px;line-height:1.8">Agent自己批准自己。</p>
<p style="margin:0 0 8px;line-height:1.8">人之所以要留在流程里，和写代码的速度无关。系统最终服务的是人，后果也得有人承担。</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨坦言，AI行业对这些风险的参与仍然不足</p>
<p style="margin:0 0 8px;line-height:1.8">AI</p>
<p style="margin:0 0 8px;line-height:1.8">会不会让</p>
<p style="margin:0 0 8px;line-height:1.8">“</p>
<p style="margin:0 0 8px;line-height:1.8">效率</p>
<p style="margin:0 0 8px;line-height:1.8">”</p>
<p style="margin:0 0 8px;line-height:1.8">变成唯一标准</p>
<p style="margin:0 0 8px;line-height:1.8">“AI will either be the greatest equalizer ever invented”</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨：AI可能成为人类发明过的、最强大的公平工具。</p>
<p style="margin:0 0 8px;line-height:1.8">但</p>
<p style="margin:0 0 8px;line-height:1.8">“可能”不是结果。</p>
<p style="margin:0 0 8px;line-height:1.8">同一套技术，既能让小团队获得过去只有大公司才有的研发能力，也能让公司更快削减初级岗位。收益落到谁手里，取决于企业怎样分配效率红利，也取决于新人还能不能获得学习复杂系统的机会。</p>
<p style="margin:0 0 8px;line-height:1.8">这对开发团队是个很现实的问题。</p>
<p style="margin:0 0 8px;line-height:1.8">如果考核只盯代码量和交付速度，</p>
<p style="margin:0 0 8px;line-height:1.8">Agent一定会显得越来越划算。可代码写得越快，进入评审、测试和上线的改动也越多。没有更强的验收标准，效率提升很容易变成更多技术债和更大的事故半径。</p>
<p style="margin:0 0 8px;line-height:1.8">初级工程师过去会从修</p>
<p style="margin:0 0 8px;line-height:1.8">Bug、补测试、升级依赖中熟悉系统。大量基础任务被Agent代替后，公司不能直接要求新人跳到架构判断。</p>
<p style="margin:0 0 8px;line-height:1.8">让新人跟着一次真实改动走完理解需求、约束Agent、核对日志、灰度上线和复盘，才有可能补回被自动化拿走的训练过程。</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨没有给出一个简单的乐观答案。技术进步不会自动把收益平均分给每个人。</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨认为，解决AI带来的就业、安全和治理问题，需要全球共同参与</p>
<p style="margin:0 0 8px;line-height:1.8">对开发者来说，不能交给</p>
<p style="margin:0 0 8px;line-height:1.8">AI</p>
<p style="margin:0 0 8px;line-height:1.8">的是什么</p>
<p style="margin:0 0 8px;line-height:1.8">开发者不需要和</p>
<p style="margin:0 0 8px;line-height:1.8">Agent争夺每一行代码。更重要的是，把团队里不能自动放行的事情写清楚。</p>
<p style="margin:0 0 8px;line-height:1.8">高风险操作需要人工确认。删除数据、调整付款逻辑、读取生产密钥和直接发布，不能因为模型判断</p>
<p style="margin:0 0 8px;line-height:1.8">“有把握”就绕过审批。</p>
<p style="margin:0 0 8px;line-height:1.8">验收条件需要能够执行。</p>
<p style="margin:0 0 8px;line-height:1.8">“优化接口”没有终点；“P95延迟低于200毫秒，结果与旧接口一致，连接数不增加”才可以被测试，也可以被追责。</p>
<p style="margin:0 0 8px;line-height:1.8">Agent的过程需要留下记录。它读了哪些文件、调用过什么工具、为什么修改这段逻辑，出了问题要能回放，而不是只剩一个看起来正常的diff。</p>
<p style="margin:0 0 8px;line-height:1.8">回滚路径要先于自动化。模型可以提高改动速度，不能替团队决定一次线上损失是否值得承受。</p>
<p style="margin:0 0 8px;line-height:1.8">在</p>
<p style="margin:0 0 8px;line-height:1.8">Agent执行之外，需求、风险、上线和事故处置仍需要明确的人类责任人</p>
<p style="margin:0 0 8px;line-height:1.8">“为人保留”不必是一整份拒绝使用AI的工作，也可以是工作流里几道不允许模型自行越过的门。</p>
<p style="margin:0 0 8px;line-height:1.8">评论区：有人认为比尔盖茨</p>
<p style="margin:0 0 8px;line-height:1.8">终于悲观了，也有人认为他夸大了失业风险</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨官方视频关闭了评论。下面两条留言来自MS NOW对同一篇长文的报道视频评论区。</p>
<p style="margin:0 0 8px;line-height:1.8">一位观众问：</p>
<p style="margin:0 0 8px;line-height:1.8">“如果有一天，AI决定不再需要我们来构建它们呢？”这句话把Bill Gates文章里最沉重的担忧推到了极端：当能力和执行都交给机器，人类还能靠什么留在流程里？</p>
<p style="margin:0 0 8px;line-height:1.8">观众担忧，AI发展到一定阶段后，可能连构建AI的人也不再需要</p>
<p style="margin:0 0 8px;line-height:1.8">另一位观众完全不买账，认为比尔盖茨</p>
<p style="margin:0 0 8px;line-height:1.8">在夸大风险，甚至把这篇文章称为给AI泡沫继续吹气。</p>
<p style="margin:0 0 8px;line-height:1.8">另一位观众认为AI被严重高估，比尔盖茨的警告也有夸张成分</p>
<p style="margin:0 0 8px;line-height:1.8">两种反应都很正常。</p>
<p style="margin:0 0 8px;line-height:1.8">AI确实在提高开发效率，岗位也不会在某一天同时消失。</p>
<p style="margin:0 0 8px;line-height:1.8">但当企业发现一批任务可以用更低成本完成时，团队人数、招聘标准和培养方式一定会跟着改变。</p>
<p style="margin:0 0 8px;line-height:1.8">比尔盖茨的“为人保留”，用不着变成一条覆盖所有行业的统一红线。它提醒我们，自动化方案除了成本、速度和准确率，还要回答一个问题：谁作出最后决定，谁承担结果？</p>
<p style="margin:0 0 8px;line-height:1.8">对开发者来说，这个人不能缺席。</p>
