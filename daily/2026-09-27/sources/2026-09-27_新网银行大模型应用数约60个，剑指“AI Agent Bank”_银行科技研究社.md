# 新网银行大模型应用数约60个，剑指“AI Agent Bank”

来源：银行科技研究社
原文链接：https://mp.weixin.qq.com/s/_IY6Y7KqdL5QgFnzhbrgcQ

作为一家民营银行，四川新网银行曾定位“数字银行”，而在近几年的AI大模型浪潮之下，该行正向“AI银行”转变。近日，新网银行介绍其AI实践情况，并透露了最新的AI进展。
大模型应用数约60个，日均Token消耗量为50亿左右
据媒体报道，在近日举行的中国国际服务贸易交易会第八届中国金融科技论坛上，新网银行信息科技部副总经理詹雪峰分享了该行的智能应用实践，其中有一些关于AI应用的新进展。其分享内容比较口语化，《智探AI应用》整理了部分内容。
据悉，新网银行是一家全线上展业的银行，在建立之初即应用AI技术服务客户。在2023年之前，该行主要是基于决策式AI，彼时针对风控和客服等领域以智能技术赋能业务发展。
而在2023年，大模型技术爆发，银行业开始布局大模型。新网银行也在彼时引入首个基座大模型，上线首个大模型智能助手。
2024年，新网银行上线首个微调大模型的应用，并上线了首个智能体应用。2025年，该行则利用大模型技术升级了外呼服务，提升客服外呼的对客体验，同时构建了AI云底座，初步建成AI网关。
正是在2025年，新网银行在全行发起智擎AI+行动，旨在稳步推进智能应用落地。值得一提的是，该行人力资源部也专门制定了关于数字员工入职、试用和晋升的制度。
关于目前新网银行的AI应用能力建设，詹雪峰表示，在最底层的算力上，该行已建设私有算力，目前有100多张卡，但是以目前的AI应用来看，新网银行的AI算力不够用。因此，在部分非敏感业务的办公场景，该行引入了云厂商的SaaS服务。
新网银行的Token消耗量方面，目前的统计数据显示，AI Coding编码助手方面的Token消耗量是最大的；其次是数字员工，体现在办公场景，包括数据分析和ChatBI等应用。
据介绍，新网银行目前的大模型应用数量约60个，累计建设智能体超100个，日均Token消耗量为50亿左右。
而在新网银行的研发管理体系中，AI生成代码占比20%，统计口径为其用于生产的代码中有20%是由AI生成；测试用例方面，AI生成占比是60%。
此外，詹雪峰还透露，近期新网银行数字员工能力取得的突破主要在于对客服务方面。此前，该行是基于小模型开发对客服务的数字员工，存在较大的局限。如今随着大模型技术发展，该行基于意图识别的方式构建数字员工，使得服务更智能。
据《智探AI应用》了解，新网银行曾表示，正加速由数字银行向AI银行转变。因此，加强AI布局将是未来的核心工作。
去年全行进入大模型应用元年，未来剑指“AI Agent Bank”
从新网银行2025年报可知，该行沉淀大模型全栈能力，推进AI工程化应用。
具体而言，该行构建行领导牵头、各部门协同的“智擎AI+”工作体系，全组织、全场景、全流程推进智能化工作，打造10类数字员工及77个智能助手，形成覆盖客户触达、风险评估、内部办公等领域的智能化应用矩阵。
同时，打造异构融合的AI云算力底座，基于容器技术构建算力池化与智能调度能力，实现算力资源统一纳管、动态分配和精细化利用，配合算力热力图实时监控算力资源分配情况和利用率，推动算力利用率整体提升30%以上，支撑AI应用规模扩增。
其中，该行通过AI技术升级研发体系。围绕研发各环节打造编码、测试用例生成等10余个大模型助手，作为研发人员必备生产力工具，推动产品更快迭代上新。
值得一提的是，新网银行还强调，在技术创新方面，2025年全行进入大模型应用元年，推进大模型赋能生产经营，AI Agent在全行各业务环节取得一定进展。
因此，在新网银行的AI大模型布局上，2025年是非常重要的一年。
而在2026年6月，新网银行在活动中首次对外系统展示“智擎AI+”战略的落地全貌，包括已建成15类数字员工与100多个智能体组成的协同网络。可见，该行数字员工与智能体的类别、数量均在不断扩增。
尤其是，2026年是公认的智能体商业元年，银行业正加速智能体落地。对于新网银行来说，智能体或将是重中之重。
新网银行曾表示，AI Agent Bank正成为银行智能化发展的重要方向：当智能体具备感知、分析与执行能力，银行就不再只是系统与流程，将进一步形成数字员工与专业团队协同运作的新型服务模式。
当然，从新网银行提出的“人人AI，处处AI”转型目标来看，该行仍任重道远。
