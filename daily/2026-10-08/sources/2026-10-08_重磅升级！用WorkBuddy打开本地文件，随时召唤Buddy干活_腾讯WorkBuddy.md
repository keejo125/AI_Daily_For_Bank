# 腾讯 WorkBuddy 重磅升级：本地文件右键即可召唤 Buddy 干活

来源：腾讯WorkBuddy
原文链接：https://mp.weixin.qq.com/s/3fTnMCfITqvbz-VlQVO3og

以前想让 AI 处理一份本地文件，通常要先进入 WorkBuddy，再把文件上传到对话框里。
现在，这一步可以省掉了。
WorkBuddy
正式上线独立文件浏览器。
直接在电脑里找到一份文件，右键选择「打开方式」中的 WorkBuddy，就能在独立窗口中查看文件，并直接调用 AI 进行分析、修改或继续处理。
独立文件浏览器：
专为本地文件处理设计的 WorkBuddy 独立窗口。Word、Excel、PPT、PDF、Markdown、HTML 等文件都可以直接打开，在同一个窗口里查看、编辑，并随时调用 Buddy 处理。支持多文件标签页切换，每份文件都有自己的 Buddy 对话。无需单独下载，更新 WorkBuddy 后即可使用。
左边是当前文件，右边是 Buddy。
查看、提问、修改，都可以围绕眼前这份文件直接进行。
围绕「AI 时代的 Office」，WorkBuddy 一直在做一件事：
让
AI
更自然地进入真实的工作流程。
人机双写，让 AI 进入文档，和人一起写、一起改；
资料库，让零散资料被持续沉淀、整理和调用；
这次，独立文件浏览器让本地文件也直接成为 WorkBuddy 的工作入口。
从「先进入 WorkBuddy，再处理文件」，到「打开文件，就能直接用 AI」。
01｜本地文件，直接用 WorkBuddy 打开
右键打开，不用先把文件发进聊天框
现在，处理电脑里的本地文件时，
不用再先上传到
WorkBuddy
的聊天框。
一份正在写的 Word、刚收到的 PDF、需要继续调整的 PPT、一张 Excel 表格，或者此前由 AI 生成的 Markdown、HTML，都可以直接用 WorkBuddy 打开。
在文件夹里找到文件
，
右键选择「打开方式」中的
WorkBuddy
，就能直接进入独立文件浏览器。文件会直接展开，需要 AI 时，点击「和 WorkBuddy 对话」，就可以在右侧一边看文件，一边继续提问和处理。
比如收到一份几十页的 PDF，打开后可以直接问：
“这份文件主要讲了什么？帮我列三条重点。”
换成一张数据表，也可以直接问：
“哪几个产品卖得最好？按大区帮我排一下。”
一个窗口还能同时打开多份文件，每份文件都会以标签页的形式保留。
切换标签时，右侧的 AI 对话也会一起切换，每段对话都围绕当前这份文件展开。
设为默认打开方式，双击文件直接进入
如果平时经常用 WorkBuddy 处理文件，还可以将它设为默认打开方式。之后
双击文件，就能直接用
WorkBuddy
打开
。
02｜独立窗口里也能人机双写，改完直接存回当前文件
自己动手改，或者交给 Buddy 处理
对于支持编辑的文件，打开以后就可以像平时处理文档一样，直接在当前文件上继续修改。
WorkBuddy
原有的「人机双写」也一起跟了进来。
你可以自己动手改，也可以随时让 Buddy 参与。
比如打开一份 Word，看到背景与目标部分太长，可以直接在右侧说：“简化一下背景与目标。”
Buddy 改过的内容会以黄色色块直接标在原文中，
哪里发生了修改，一眼就能看出来。
你可以一边看修改结果，一边继续调整。
此外，你也可以先选中正文里的某一段，再让 Buddy 针对这部分改写、润色或补充。Buddy 会直接修改对应位置，结果也会落到当前文档里。
不只是 Word
Excel 里的数据、PPT 里的文字和页面内容，也可以边看边让 Buddy 处理；Markdown 可以直接在排版好的内容上编辑，也支持继续用 Markdown 语法写作；HTML 则可以在网页预览和编辑状态之间切换，需要调整时同样可以让 Buddy 参与。
改的就是当前文件，保存也直接回到本地
更重要的是，无论自己改，还是让 Buddy 帮你改，
处理的始终是电脑里的这份本地文件
。
Word、Excel、PPT 修改完成后，点击保存或使用 Ctrl / Command + S，修改会直接写回本地文件；
Markdown
编辑后会自动保存；HTML
则会在退出编辑状态时自动保存
。
如果还有未保存的修改，关闭标签或窗口时也会先提醒你保存。想保留修改前的版本，也可以像平时一样先「另存为」一份，再继续调整。
这样，文件从打开、修改到保存都可以在原来的位置完成，不用再反复下载新版本，也不用在文件夹里堆出“最终版”“最终版 2”“最终版真的最终”。
03｜从当前文件出发，继续往下做
现有文件里的内容，也可以让 WorkBuddy 帮你换一种方式呈现。
比如打开一张 Excel，可以直接说：“按这份数据，帮我做一个网页版汇报。”
WorkBuddy 会基于当前文件继续处理。你可以直接从已有内容出发，也可以先把原文件调整好，再基于最新版本生成下一步需要的内容。
如果 Buddy 生成了新的文件，会
默认保存在原文件所在的目录里
。点击生成结果，还可以直接在当前窗口里以新的标签页打开，继续查看和处理。
处理完成后，新文件也可以直接分享，或者上传到资料库、腾讯文档进行后续的协作。
04｜Markdown、HTML：电脑直接改，微信也能打开
Markdown 和 HTML 经常是 AI 生成内容时会用到的格式，但保存到本地以后，想重新打开、继续修改，往往没有普通文档那么顺手。
现在，这两类文件，不管是由 WorkBuddy 生成的，还是来自其他工具、其他人或此前保存的文件，
就可以直接用
WorkBuddy
独立文件浏览器打开，继续查看、编辑，或者交给
Buddy
处理。
在微信里收到这两类文件，也可以
直接通过
WorkBuddy
小程序预览，或加入对话继续处理
。
电脑端：本地 Markdown、HTML，直接打开进行人机双写
在电脑上，Markdown 打开以后，会
直接呈现排版好的内容，可以像普通文档一样点进去修改
；如果习惯 Markdown 语法，也可以继续用 md 语法写作，输入内容会同步渲染。
比如，输入两个井号加一个空格，对应的标题样式就会直接显示出来
需要 AI 帮忙时，也可以继续让 Buddy 改写、润色或补充内容，修改结果直接落到当前这份 Markdown 里。
编辑内容会自动保存，不需要再单独点保存。
HTML
打开后，默认以网页形式预览。需要调整时，可以进入编辑状态，
自己修改内容，也可以继续让 Buddy 参与。
改完之后再回到预览，就能直接看到调整后的页面效果；退出编辑状态时，修改也会自动保存回当前 HTML 文件。
微信端：不用切换软件，直接用 WorkBuddy 小程序打开
在微信中收到 Markdown 或 HTML 后，
选择「用其他应用打开」
，就可以通过 WorkBuddy 小程序直接预览。
【图 8：微信 → 用其他应用打开 → WorkBuddy 小程序预览】
更重要的是，用 WorkBuddy 小程序打开后，后续可以直
接以小程序预览页的形式转发出去，其他人点开就能直接看。
如果只是想看看内容，直接预览即可；如果还想让 AI 继续处理，可以把当前文件加入对话，再告诉 Buddy：
“帮我总结一下这份文件的重点。”
“把这段内容改得更适合发给客户。”
“帮我把这份内容重新整理得更清楚一点。”
Buddy 会继续围绕这份文件进行总结、改写或润色。目前单次支持处理一个文件，
预览文件本身不消耗积分。
【小程序加入对话 → AI 继续处理】
从电脑端继续编辑，到微信里收到文件后直接预览、继续问 AI，Markdown 和 HTML 也能更自然地接入日常的文件处理流程。
最后，补充几件你可能会关心的事
Q：
打开和编辑本地文件会消耗积分吗？
不会。查看、编辑本地文件本身不消耗积分；只有在右侧对话中让 Buddy 总结、改写、生成新内容等使用 AI 能力时，才会根据实际任务消耗积分。
Q：
这么打开文件，WorkBuddy 会读取电脑里的其他文件吗？
不会。独立文件浏览器只会读取你主动打开或添加的文件，不会遍历或扫描电脑磁盘。
Q：
同一份文件在其他应用里也被修改了，WorkBuddy 会怎么处理？
不会自动覆盖。WorkBuddy 会提示文件在别处发生了修改，你可以选择刷新到最新版本，或将当前内容另存为一份副本。
当 AI 能做的事情越来越多，我们还需要为了使用 AI，改变多少原本的工作习惯？
WorkBuddy
的答案是：尽可能少。
与其让人不断适应 AI，不如让 AI 直接进入我们原本的工作流。
所以，使用 WorkBuddy 不一定要从聊天框开始。
你也可以从电脑里已有的一份文件开始：打开它、读懂它、修改它，再基于它继续完成下一步工作。
