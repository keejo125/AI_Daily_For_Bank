# 编程能力提高 50%！GLM-5.3 满分通过了 GPT-5.6 给的 Coding 测试

> 原文链接：https://www.infoq.cn/article/xWyWwu4ZNptlhpb15tia
> 来源：InfoQ

## 核心要点

- GLM-5.3 于北京时间 8 月 14 日发布，围绕 GLM-5.2 长程 RL 技术栈扩大训练规模（更多任务环境、更高多样性、更多算力），已向全部 Coding Plan 用户开放，可用于 ZCode、Claude Code、OpenCode 等 Coding Agent。
- “AI 测 AI”：GPT-5.6 sol 设计可直接交付 ZCode 的测试包（5 项共 100 分），GLM-5.3 约 13 分钟满分通过，GPT-5.6 评 A−；但测试仅为小型单文件 Python 任务，不代表大型系统工程或真实安全任务能力。
- 性能提升全部来自后训练：IndexShare（长上下文）、SAO（长程 RL）、slime（大规模异步训练，训练侧 Megatron + Rollout 侧 SGLang），使长程 Coding RL 端到端训练吞吐提升超 2.3 倍。
- 智谱扩大“接近真实工程”的训练环境，让任务从“写一段代码”变成“独立承担一项工程”；并建立 Research Agent 生成环境 + Judge Agent 验证 + 自动 Verifier 的流水线。
- 意外强化网络安全：CyberGym 84.5%（高于 GPT-5.6 Sol 83.6%），并在真实开源项目发现 2436 个漏洞（1097 高危/严重），含部分存在数十年的历史漏洞。约两周后公开模型权重。
