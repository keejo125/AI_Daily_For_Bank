# 3万个Agent 进行自我迭代，26% AI研发已由Claude主导：RSI 走向落地、AI 开始参与制造下一代 AI

来源：CSDN
原文链接：https://mp.weixin.qq.com/s/AKPq-2VqlJjJvJSSh-NCcA

责编 | 梦依丹
出品 | CSDN（ID：CSDNnews）
2026 年，RSI——Recursive Self-Improvement 递归自我改进突然成了 AI 圈最密集出现的关键词之一。
Anthropic 最新数据：26% AI 研发由 Claude 主导，3 万 Agent 已进入研发流程
就在刚刚，Anthropic 公布了一组非常有冲击力的内部数据：截至 2026 年 8 月，Claude 已经能够主导 Anthropic 26% 的 AI 研发工作，90% 以上的研发任务至少已经进入「
AI 协作
」阶段。 在其最常用的内部研发平台上，同时约有 3 万个 Agent 正在参与研究和工程工作。
出处：https://www.anthropic.com/institute/measuring-pace-of-ai-development
Anthropic 甚至专门构建了一个 R&D Automation Index，用来衡量「
AI 正在多大程度上参与构建下一代 AI
」。官方给出的理由很直接：只有把这个过程量化，才能更清楚地判断，我们距离真正的 Recursive Self-Improvement 还有多远。
过去，RSI 更像是一个面向未来的概念，现在，它开始有了可以被测量的进度条。
Anthropic 之外，OpenAI 已经让 Agent 大规模进入内部研究流程，Google DeepMind 的 Dream-RSI 则直接尝试让 Agent 持续优化自己的探索策略。国内，智谱、DeepSeek、月之暗面、阿里等团队也正沿着 Fully Self-Training、强化学习、Agentic Scaling、世界模型与持续学习等不同路径，推进“让 AI 从完成任务，走向持续获得经验并变得更强”。
技术路线并不完全一样，但方向正在越来越一致：
AI 正从“被研发的对象”，进入“研发下一代 AI 的过程本身”
。
大模型技术：从 Agentic Scaling 到 RSI
也正是在这样的背景下，2026 奇点智能技术大会特别设置了 「大模型技术：从 Agentic Scaling 到 RSI」专题。我们希望把这个正在快速发生的变化拆开来讲：从 Agentic Scaling → 强化学习 → 数据飞轮 → Agent 自进化 → RSI 的技术链路，2026 奇点智能技术大会邀请了来自 OpenAI、腾讯、面壁智能、高校
及开源社区的一线研究者和工程实践者。
俞扬：没有强化学习，就很难谈真正的持续进化
南京大学人工智能学院副院长、教授俞扬，长期从事机器学习与强化学习研究。
他此次分享的主题是：《大模型强化学习》。
如果说 RSI 描绘的是“AI 持续变强”的目标，那么强化学习就是目前最重要的技术底座之一。
DeepSeek R1 之后，行业已经越来越清楚地看到：模型能力提升，并不一定全部来自更多人工示范数据。当 Reward、环境和探索机制设计得足够好，模型可以在不断尝试和反馈中发展出新的推理策略。
但真正难的问题也随之而来：Reward 怎么设计？探索如何 Scale？模型究竟是在学习新能力，还是只是在优化已有策略？
这些都是从 RL 走向 RSI 绕不开的基础问题。
李宇轩：AI 不只“帮助研发”，而是开始直接“制造 AI”
面壁智能技术合伙人、智能进化首席科学家李宇轩，把这条路线推进到了更具体的工程实践。
他的演讲主题是《AI 制造 AI：从五级演进框架到 AI Infra 的自主生成》。
他提出了一套 AI 制造 AI 的五级演进框架，从辅助建议一直走向自主探索，并进一步提出“锻造工程”——当 AI 写代码的成本快速下降，不再追求一套通用实现覆盖所有场景，而是让 AI 针对每个具体需求生成专用、垂直整合的实现。
更重要的是，这已经不是概念实验。
他的团队已经把这种方法用于训练框架、算子库和推理内核：让 AI 开始直接参与生成和优化支撑 AI 自身运行的基础设施。
这其实已经触碰到了 RSI 最核心的一层：AI 开始参与建设下一代 AI 所依赖的系
统。
张俊林：到底什么才算 RSI？哪些只是“看起来像自进化”？
新浪微博首席科学家及 AI 研发部负责人 张俊林此次的主题直接指向核心——《AI 自我迭代改进（RSI）：方法、实践及其局限》。
这也是整个专题里承担“方法与边界”梳理的一场分享。
从 2023 年的 《AI for AI：如何让大模型来制作大模型》，到 2025 年对 DeepSeek R1、强化学习与深度推理的拆解，再到今年的 RSI，张俊林其实一直在沿着同一条问题链向前追：AI 能在多大程度上参与改进 AI？
而到了今天，更需要分清：
Self-Refine 是 RSI 吗？
Memory 自动更新算不算？
Agent 修改 Prompt、Tool、Workflow 和模型真正获得新能力有什么区别？
如果模型自己生成数据、自己评测、自己训练，如何避免错误被不断放大？
所以他的题目后半句——“及其局限”——可能比“RSI”三个字本身更重要。
董汉德：自进化真正进入产品，要先跑通“用户—数据—模型”飞轮
到了真实产品里，RSI 又会变成另一种形态。
腾讯 WorkBuddy 模型研发负责人董汉德将带来《LLM Agent 的模型数据飞轮——WorkBuddy 持续学习经验分享》。
随着 Agent 被越来越多用户真实使用，大量“Agent—环境—用户”的交互轨迹开始产生。
这些数据里不仅有成功案例，还有用户什么时候介入、Agent 在哪里犯错、怎样修正、什么反馈真正有价值。
真正困难的，是如何把这些产品经验重新转化成有效训练信号，让下一代模型真的因此变强。
WorkBuddy 正在尝试跑通的，就是这样一套：用户 → 数据 → 模型 → 产品 → 新数据的持续学习闭环。
相比“模型突然学会自我进化”，这可能反而是 RSI 最现实、最先大规模发生的形态。
郑耀威：不重新训练大模型，Harness 能不能先自己进化？
PenguinHarness、LlamaFactory 作者郑耀威，给出的是一条更轻量、也更工程化的路线：《低成本、高收益的自进化 Agent 闭环构建实践：从 LlamaFactory 到 PenguinHarness 的技术演进》。
他的核心问题非常直接：如果暂时没有能力频繁重新训练大模型，能不能先让 Agent 的外部系统持续进化？
PenguinHarness 把这个过程做成一个可运行闭环：
数据生成 → 多智能体评估 → Harness 自动迭代 → Benchmark 验证 → 再进入下一轮优化。
在已有实验中，这套方法实现了平均准确率提升 18.8%、Token 成本降低 7.5%。
这意味着，RSI 并不一定从“修改模型参数”开始。
Prompt、Memory、Skill、Tool、Workflow，乃至整个 Harness，都可能率先成为 AI 自我改进的对象。
陈秋远：Coding Agent 在 RSI 上的实践
腾讯 CodeBuddy & WorkBuddy 模型研发高级研究员陈秋远，目前参与 Coding Agent 模型研发，并直接负责其中的 RSI（Recursive Self-Improvement）方向。
他的目标非常明确：让模型获得持续学习的智能。
Coding Agent 是一个尤其适合探索 RSI 的场景。因为代码世界天然拥有大量可以被机器验证的反馈：代码能不能编译、测试能不能通过、Bug 是否修复、性能有没有提升。
Agent 可以执行任务、观察结果、分析失败、修改策略，再重新执行。
因此 Coding Agent 很可能成为 RSI 最早真正跑出闭环的场景之一——从“一次把代码写对”，进一步走向：从每一次任务里学习，让下一次做得更好。
从 RSI 到整个 AI 技术栈，2026 奇点智能技术大会把AI 落地真问题带到现场
RSI 只是今年技术变化里最值得追的一条主线。
当模型能力继续向前，真正摆在技术团队面前的问题已经越来越具体：
Agent 怎么真正进入生产？
AI Coding 怎么从提效工具走向研发系统？
世界模型和 Physical AI 如何跨过真实世界的数据与因果鸿沟？
AI Infra 又该怎样支撑更长链路、更高频率、更复杂的智能体运行？
围绕这些正在发生的变化，2026 奇点智能技术大会将于 11 月 20—21 日在北京万达文华酒店举行。
大会将汇聚 70+ 一线研究者与技术专家、18 大前沿技术专题、1000+ 行业技术人，从大模型自进化、Agent、AI 原生软件研发、多模态与世界模型，到 Physical AI、AI Infra、企业级 AI 落地等方向，集中呈现来自一线团队的最新研究与真实工程实践。
除了「大模型技术：从 Agentic Scaling 到 RSI」专场，大会还将围绕AI 原生软件研发、智能体应用与开发实践、多模态与世界模型、具身智能与 Physical AI、AI Infra 与算力优化、企业级 AI 落地等方向展开。
我们更希望现场讨论的，不只是“哪个模型又刷新了榜单”，而是这些能力真正进入系统之后：怎么训练、怎么评测、怎么形成反馈闭环、怎么控制成本、怎么持续进化，以及最后怎么跑进真实业务。
