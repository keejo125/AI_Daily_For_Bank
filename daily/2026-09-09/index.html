NVIDIA 发布 CUDA Rust：用 Rust 编写 GPU 内核的一等语言
MarkTechPost
NVIDIA 宣布 CUDA Rust，推动 Rust 成为编写 GPU kernel 的一等语言。配套两个 NVlabs 开源项目：cuda-oxide（SIMT 模型）与 cutile-rs（Tile 模型），均原生编译 Rust kernel，并借助 Rust 所有权规则在编译期拦截别名 bug。cutile-rs 已发布于 crates.io，支持稳定版 Rust 1.89+，用于 Hugging Face Grout 推理引擎与 mistral.rs；cuda-oxide 仍处早期 alpha。AI 系统层（推理引擎、驱动、Agent 运行时）正加速向 Rust 迁移。
Shopify 推出 Gisting 新技术：将大模型系统提示词压缩为主旨词元
InfoQ

单样本校准、零推理开销，免训练LoRA合并框架上线 | ICML'26
量子位
vivo BlueImage Lab 与南京大学等提出 SSR-Merge（Subspace Signal Routing），解决多 LoRA 合并互相干扰、画风串味难题。现有方法（Task Arithmetic 相加、TIES/DARE 稀疏化）本质在参数空间硬碰硬，靠牺牲能力换稳定。SSR-Merge 用子空间信号路由从数学上解耦干扰：实验显示传统 DARE 合并激活图一片通红（指令错误唤起大量无关模块），而 SSR-Merge 接近干净对角线。方法具备单样本校准、零推理开销、免训练特性，已发表于 ICML'26。
