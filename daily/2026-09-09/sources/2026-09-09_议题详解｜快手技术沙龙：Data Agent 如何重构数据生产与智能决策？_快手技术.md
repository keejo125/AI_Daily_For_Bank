# 议题详解｜快手技术沙龙：Data Agent 如何重构数据生产与智能决策？

来源：快手技术
原文链接：https://mp.weixin.qq.com/s/OuMRefNuFlYnphiwdnp1Yw

过去，数据智能更多停留在“问答”和“辅助分析”层面；而现在，Data Agent 正在走向更深的业务现场——它不仅能理解问题、调用工具、生成分析结论，还开始参与取数、归因、报告生成、异常诊断、A/B 实验分析乃至数据生产等关键环节。 但要让 Data Agent 真正成为日常工作中的可靠伙伴，难点并不只在模型本身，更在于如何构建可控的基础设施、可信的知识体系、可持续进化的记忆机制，以及能在复杂业务场景中稳定落地的工程能力。
9月19日，快手技术沙龙第5期将围绕
「Data Agent：数据生产与智能决策新范式」
展开分享，来自
快手数据平台部、云器科技与腾讯
的多位嘉宾，将结合一线实践，系统探讨 Data Agent 如何从“能用”走向“可信、可协同”，并进一步重构数据生产与智能决策方式。
【活动报名】
01
《让数据智能成为工作日常：快手 Data Agent 的规模化应用实践》
分享
人：
张蕤｜快手数据平台产品技术中心负责人
议题概要：
大模型降低了数据问答的门槛，但 Data Agent 要真正融入日常工作，仅靠模型能力还不够：它既要理解复杂业务、完成长链路任务、交付可信结果，也要支撑多角色、多场景的规模化应用。
快手 Data Agent 从单点数据助手逐步演进为统一的数据智能服务，覆盖找数取数、分析归因、报告生成、A/B 实验分析、数据生产、埋点分析、画像服务等环节，已在各业务线实现规模化应用。本次分享将结合快手实践，介绍从 Workflow 到 Agentic 的产品演进，父子 Agent 架构、Skill 体系、知识飞轮、评测与质量保障等关键设计，并通过真实案例，展现 Data Agent 如何从“可用”走向“常用、好用”，让数据智能真正成为工作日常。
02
《Data Agent 的设计与背后的基础设施》
分享
人：
关涛｜云器科技联合创始人&CTO
议题概要：
为什么通用 Agent 很难直接进入数据生产系统？面对准确率、可解释性和人机协同等要求，Data Agent 应该如何设计？模型、工具、数据平台与基础设施之间，又该如何分工？本次分享将结合 DEAgent 的实践，探讨如何构建真正可靠、可控、可持续演进的 Data Agent。
03
《Data Agent 重构快手电商数据生产和消费方式》
分享
人：
方彬｜快手电商用增营销&支付数据负责人
议题概要：
随着快手 Data Agent 产品的逐步成熟，但如何利用 Data Agent 在实际业务场景顺利跑通并带来实质提效是 BP 侧面临的核心问题。在智能化探索过程中，从 Agent 的答非所问到精确答疑、从业务侧的临时取数到复杂报告生成、从数据分析走向生产提效都无不一步一坎，本次演讲结合 Data Agent 的演进方向，重点介绍 Data Agent 在快手电商业务场景的实际落地，从知识库建设、取数 Skill 构建、准确性保障、智能研发包实践等一系列解决方案展开介绍。
04
《灯塔 AI 的记忆工程与知识工程 —— 有记忆、有知识、会进化的 AI 伙伴》
分享
人：
王思懿｜腾讯 PCG 大数据平台部 Agent 工程负责人
议题概要：
随着 AI 助手深入企业场景，传统无状态 AI 的局限愈发明显：每次对话从零开始、上下文频繁丢失、团队协作中同一口径反复确认，导致效率难以提升。灯塔AI项目选择「记忆工程 + 知识工程」双轨并行的架构，致力于打造可持续沉淀、动态进化的企业级 AI 伙伴。
在知识工程侧，我们同时覆盖结构化数仓与非结构化文档两类核心知识源：针对数仓元数据、SQL 资产、血缘、看板等，采用确定性解码与受 Schema 约束的 LLM 抽取相结合，并引入 Extractor-Adversary-Arbiter 对抗性质量审查机制，确保抽象结果可信、可归因；针对业务文档、周报日报等，保留原文、向量、知识图谱三种形态，支持Agentic 多路检索。两类知识最终通过统一的生产-消费-治理闭环持续校准，避免知识库越积越乱。
在记忆工程侧，我们设计了三类记忆——个人记忆、项目记忆、每日日志，并支持多种记忆注入方式。每条记忆都具备完整的生命周期，使记忆规模自收敛、召回质量随使用提升。
本次演讲将围绕上述两条主线，分享落地过程中的关键难点——包括结构化数仓结合非结构化文档的知识建模、记忆生命周期管理、知识自我进化的评判标准——以及对应的解决思路与实践经验，最终呈现多源知识融合、记忆共享、知识自净化等核心能力。
05
《Data Agent 驱动的智能化 A/B 实验分析——从归因洞察到实验决策》
分享
人：
覃侃｜快手 A/B 实验平台产品技术负责人
议题概要：
传统 A/B 实验分析往往依赖人工看数取数、经验判断和多轮沟通，面对复杂指标体系与海量实验，容易出现分析链路长、归因效率低、结论难复用等问题。快手 A/B 实验平台选择以 Data Agent 为统一智能入口，将实验元信息、指标体系、数科知识、分析工具与平台能力封装为可编排的 Skill，覆盖智能报告、指标解读、异常诊断、异动归因和实验决策等场景。本次分享将介绍平台分析方式从指标看板分析、实验洞察分析到 Data Agent 驱动的智能化分析的演进路线、架构设计和产品实践。落地后，平台降低了实验分析门槛，缩短了从发现问题到形成结论的链路，并将专家经验沉淀为可复用能力，提升实验分析与决策效率。
