# 阿里云 Agent Sandbox 重磅发布，构建智能体基础设施底座

来源：阿里云基础设施
原文链接：https://mp.weixin.qq.com/s/oJwamxNmU3elJbQFe1dVAw

9月22日，阿里云在云栖大会上重磅发布为智能而生的新算力形态——
阿里云智能体沙箱 Agent Sandbox
。阿里云智能集团研发副总裁、弹性计算产品线负责人吴结生在会上表示，该产品将为每一个 Agent 提供开箱即用、极致弹性、安全隔离的云上执行环境，全力助力企业与开发者将 Agent 从原型验证加速推向生产运行。
吴结生在云栖大会技术主论坛发布阿里云 Agent Sandbox
阿里云 Agent Sandbox， 一方面满足模型强化学习 Agentic RL 和模型 RSI 自我进化的需求，提供毫秒级交付，高并发启动，和百万级智能体的脉冲式弹性伸缩，让模型学得更快和更加高效，不断提升模型的智能。另一方面，在 Agent Serving 和 Agent Use 场景，为 Agent 提供工具调用、代码执行以及大规模训练评测等开箱即用、极致弹性、安全可靠的执行环境。每分钟创建吞吐十万个沙箱，基于模板创建沙箱 P99 低于 180 毫秒，深休眠唤醒 P99 低于 600 毫秒，达到业界领先。兼容 E2B API，并提供 Kubernetes 原生接口，满足从个人开发者到企业级 Agent 平台的规模化运行需求。
从 Agentic RL 和模型 RSI
到 Agent Serving 和 Agent Use，承载 Agent 的每一次行动
在 Agentic RL 和模型 RSI 场景中，
模型需要驱动大量 Agent 与环境反复交互，完成 Rollout、Reward 计算和独立评测。阿里云 Agent Sandbox 支持批量 reset、fork 与 replay，单 Region 可承载百万级 Sandbox，创建吞吐可达每分钟 10 万个，为训练、评测与模型自主进化提供大规模并发执行能力。
在 Agent Serving 和 Agent Use 场景中，
用户请求可能瞬时涌入，Agent 需要即时创建隔离环境，执行代码、操作文件、调用 MCP 工具或完成浏览器自动化。对于等待模型响应、人工确认或外部系统返回的长任务，阿里云 Agent Sandbox 可保留工作目录、文件和运行状态，支持暂停、深休眠与快速唤醒，让 Agent 从“能够调用工具”走向“能够稳定完成任务”。
针对智能体负载特点，
阿里云 Agent Sandbox 完成五项系统级优化
第一，软硬一体的安全隔离。 阿里云通过 CIPU 云基础设施处理器与虚拟化技术协同优化，为每个 Agent 提供 MicroVM 级安全隔离环境。结合 Non-root、只读根文件系统、禁止提权、VPC 和 NetworkPolicy，限制不可信代码和工具调用的影响范围。
第二，面向脉冲负载的极致弹性。 针对 Agentic RL、模型 RSI 和在线 Serving 中集中爆发的资源需求，阿里云 Agent Sandbox 支持
每分钟创建 10 万个沙箱
，单 Region 支持
百万级 Sandbox
，在训练任务和用户请求到来时快速扩容，任务结束后及时回收。
第三，毫秒级环境交付。 通过分级镜像缓存、批量调度、MicroVM 快照恢复、按页加载和网络资源预准备，官方模板或自定义模板预热后，
沙箱创建与冷启动 P99 小于 180 毫秒
；资源池预热后，
热启动 P99 小于 20 毫秒
。
第四，深休眠与状态恢复。 对于等待模型、人工确认或外部系统的长任务，沙箱可以保存任务状态并进入深休眠，释放 CPU 和内存资源；需要继续执行时，
深休眠唤醒 P99 小于 600 毫秒
，在保障任务连续性的同时降低空闲成本。
第五，开放接口加速生态集成。 面向 Agent 开发者和企业应用团队，Developer API 原生兼容 E2B，可快速完成代码执行、文件操作和浏览器自动化；面向 AI Infra 和平台工程团队，Kubernetes API 支持将沙箱纳入既有资源编排、安全策略和运维治理体系。
三档算力 QoS，按需平衡性能与成本
阿里云 Agent Sandbox 提供业界极具竞争力的定价，包含经济型、通用型和性能型三档算力 QoS：经济型面向价格敏感、成本优先的任务，vCPU 0.060 元/vCPU/小时、内存 0.030 元/GiB/小时；通用型面向生产级沙箱，是默认推荐配置，vCPU 0.078 元/vCPU/小时、内存 0.039 元/GiB/小时；性能型采用专属资源池刚性交付，满足算力零波动需求，vCPU 0.120 元/vCPU/小时、内存 0.060 元/GiB/小时。三档均按秒计费，深休眠时仅收取磁盘费用，让企业按任务价值灵活选配资源，综合 TCO 最高可降低 70%。
阿里云 Agent Sandbox，业界主流选择
在 Agentic RL/Eval 场景中，阿里云百炼以阿里云 Agent Sandbox 承载 Rollout、Reward 和独立评测环境，复用代码、环境与配置，打通训练、评测和应用执行闭环。
在大规模 Agent Serving 场景中，MiniMax 基于阿里云 Agent Sandbox 在 10 秒内拉起 5,000 个沙箱，整体 TCO 降低 25%；月之暗面 Kimi 实现每分钟数万个沙箱弹性扩容，启动时间缩短 50%，以弹性供给支撑业务稳定响应。
在企业级 Agent Use 场景中，千问办公、理想汽车、金山办公和前程无忧分别将阿里云 Agent Sandbox 用于办公任务、企业内部 AI 助手、代码与浏览器执行以及 AI 招聘助手，通过安全隔离、状态保持和弹性供给推动智能体进入生产环境。
“
阿里云智能集团研发副总裁，弹性计算产品线负责人吴结生表示：
我们很高兴发布阿里云智能体沙箱 Agent Sandbox，依托于阿里云的计算、网络、存储、安全等基础设施，为模型的强化学习 Agentic RL，模型的 RSI 自主进化，智能体的工具调用、代码执行、和浏览器自动化等提供安全隔离、极致弹性、开箱即用的执行环境，帮助企业和开发者实现 Agent 的规模化落地。”
