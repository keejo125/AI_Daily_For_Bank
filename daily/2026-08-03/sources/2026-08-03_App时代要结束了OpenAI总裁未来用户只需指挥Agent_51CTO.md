# App时代要结束了？OpenAI总裁：未来用户只需指挥Agent

来源：51CTO技术栈
原文链接：https://mp.weixin.qq.com/s/VDSEQGsOgbM7nSiiqTFVvA

OpenAI联合创始人兼总裁Greg Brockman接受采访，描绘Agent时代的软件新范式：

核心图景：Codex从代码补全升级为任务调度器——理解目标、拆分步骤、挑选工具、保存结果。理想界面零标签页，用户只需说出目标。App不会消失，但从用户目的地变为Agent可调用的能力集。

六个开发行动项：(1)拆出稳定服务API/MCP (2)JSON Schema约束输入输出 (3)幂等键+Job ID防重入 (4)可复现运行镜像 (5)按任务发放最小权限 (6)全审计可回放。

UI转型：从操作界面→人工接管台，涉及付款/发布/删除/密钥时人审批。权限按任务切开，凭据临时签发后立即回收。
