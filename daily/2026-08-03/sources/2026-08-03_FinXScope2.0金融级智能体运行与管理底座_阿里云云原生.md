# FinXScope 2.0：金融级智能体运行与管理底座

来源：阿里云云原生
原文链接：https://mp.weixin.qq.com/s/g012Fu3rjUMkZLPCDHr-Eg

阿里云开源的金融级智能体平台 FinXScope 2.0，基于 AgentScope Java 2.0，完成从"单智能体框架"到"企业级智能体运行与管理平台"的跨越。

六层标准化架构：接入层→意图层→编排层→能力层→基础层→基础设施层。

双模执行架构：Low-code（配置驱动）降低门槛，Pro-code（编码扩展）保持灵活性上限。

2.0 核心新增：
- 多智能体协作：8种编排策略、DAG图执行器（层内并行层间串行）、A2A跨Agent协议
- 三级权限安全：用户-Agent-Skill三级模型、FILTER/REJECT双模式、沙箱执行
- 可观测性：BizLogger双模输出、ObservabilityHook自动观测
- 高可用：STM→Redis、LTM→PostgreSQL、配置热更新、完全无状态
- HITL人工介入：记忆快照与断点续传、分布式挂起持久化
- TodoList任务管理、MCP配置管理

核心主张：不做万能AI应用，做金融机构可靠的智能体运行与管理底座。
