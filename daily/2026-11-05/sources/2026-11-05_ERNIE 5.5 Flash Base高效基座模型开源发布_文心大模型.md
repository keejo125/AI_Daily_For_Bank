# ERNIE 5.5 Flash Base高效基座模型开源发布

来源：文心大模型
原文链接：https://mp.weixin.qq.com/s/mH6AG95BUsHfQ-Fh9aTj-g

今天，我们发布 ERNIE-5.5-Flash-Base，开放 ERNIE 5.5 Flash 预训练终点的权重。
它是一个稀疏 MoE 语言模型，总参数 280B，每 token 激活 14B，在 33.5T tokens 上从零完成预训练；最长训练上下文为 128K，微调与推理支持 1M tokens 上下文。本次发布的权重未经中训练与后训练，可作为领域适配、指令微调和强化学习研究的共同起点。
为什么发布 Base 模型
不同的领域、推理任务和 Agent 应用，需要不同的数据、训练目标与行为策略。开放预训练终点权重，让开发者能够在已有的通用能力之上，自行选择模型下一阶段的训练方向，把资源投入各自关心的能力、任务与训练方法。
后续训练中的反复采样，以及 Agent 应用中的多步交互和长上下文处理，都会持续累积计算与存储开销。因此，我们从模型设计之初就把效率作为重要目标：从注意力、残差连接到 MoE 层和输出头，逐个组件审视能力与效率的关系，将激活计算、KV cache 和长上下文处理开销纳入整体设计。
核心亮点
开放后续训练的起点：
提供未经中训练与后训练的 Base 权重，支持社区自行探索领域适配、推理强化和 Agent 训练路线。
面向持续训练与推理的效率设计：
结合稀疏 MoE 与混合稀疏注意力，在架构层面统筹模型容量、激活计算和长上下文开销。
全面的数据，高效的训练：
广覆盖、高质量的预训练数据为后续训练打下全面的能力底座；与模型结构协同设计的训练系统，保证大规模预训练高效进行。
阶段明确的研究基线：
以预训练终点的统一 checkpoint，支持不同训练方法的对照评估与增益分析。
模型结构
ERNIE 5.5 Flash 共 43 层 Transformer。我们围绕一个目标重新审视了几乎每个组件：最大化单位激活参数、单位 KV cache 字节的效果。
注意力：
混合稀疏注意力。43 层中有 37 层采用重度压缩注意力（HCA），每 128 个 token 只缓存一条；其余 6 层采用多头潜在注意力（MLA）配合稀疏注意力（DSA），保留每个 token。各注意力层内部还采用了低秩门控与 Virtual Head Attention（VHA）。
Multi-Router Latent MoE 聚合多个独立初始化的 sigmoid 路由器评分
。这些路由器在训练中形成高度分化的专家偏好，对噪声特征和分布变化更稳健，路由打分与专家实际效用的相关性明显提升。共使用 512 个路由专家，每个 token 选择其中 10 个，另加 1 个共享专家；专家在 2048 维隐空间中计算，通信量和专家计算量约减半。
MultiMax 输出头：
单一的 softmax 温度难以让输出分布既集中又保留多个合理候选。MultiMax 改用可学习的分段温度，将不合理 token 的零散概率压低至接近零，同时保留几个合理候选；训练开销可忽略、不增加显存，同时显著降低预训练 loss。
ECHO：
用主干自身的最后一层取代 MTP 模块做未来预测，多步损失直接作用于生成下一个 token 的参数，推理与代码收益明显。ERNIE 5.5 Flash 以单步 ECHO 预训练，该层作投机解码的草稿模型时涌现外推特性：同样只训练一步，多步起草质量大幅优于辅助 MTP。
其他组件：
mHC 流形约束超连接，每层读写 4 条并行残差流；全新 BPE 分词器，词表约 200K，数字从右到左、最多三位一组切分。
预训练
ERNIE-5.5-Flash-Base 在 33.5T tokens 上从零完成预训练，采用 Muon 优化器与 FP8 混合精度。预训练语料覆盖广泛的领域与语言，并重点建设了三个方向：
网页数据：
多语言网页抓取、高保真文本抽取与模型驱动的多维质量过滤。
代码数据：
仓库与网页代码经非代码过滤、去重与质量分级，并补充 commit、issue、pull request、代码评审、自动生成的测试、经 CI 验证的修复等软件演化与执行验证类数据。
长文数据：
精选的天然长文档、混入语义相近检索干扰文本的长序列，以及合成的检索、基于引用的问答与多跳问答数据。
训练系统与模型结构协同设计。优化器采用分布式 Muon：在数千卡规模下，Dense 参数与 MoE 参数的跨机通信合并为一次集合通信，降低了跨机时延与抖动。注意力算子采用基于 CuTe-DSL 的 FlashMask-4，支持 SM90 与 SM100 架构，head dim 最高支持 576（qk）/ 512（v），可直接用于 HCA 层 512 维宽头的计算。
评测
我们在 30 项 Benchmark 上评测了 ERNIE-5.5-Flash-Base，涵盖综合、知识、理科、推理、多语言、代码与长上下文七类能力。对比模型选取截至发布时我们能找到的、规模相近的最新开源 Base 模型 DeepSeek-V4-Flash-Base、Hy3-preview-Base 与 MiMo-V2.5-Base，四个模型均基于各自公开发布的 checkpoint、使用同一套评测框架。ERNIE-5.5-Flash-Base 在各能力维度上均表现良好；长上下文方面，尽管 43 层中有 37 层在 128 倍压缩后的序列上做注意力，6 层 MLA-DSA 已足以支撑细粒度检索。完整表格见 Hugging Face 模型卡。
如何使用
权重已在 Hugging Face 上线，分 FP8（baidu/ERNIE-5.5-Flash-Base）和 BF16（baidu/ERNIE-5.5-Flash-Base-BF16）两个版本，许可协议为 ERNIE 5.5 Flash Base Model License Agreement v1.0。
模型卡提供了基于 SGLang 与 vLLM 的完整部署与调用示例。微调方面，NVIDIA Megatron-Bridge 已支持该模型，并提供了 ERNIE 5.5 的示例。
Base 模型只是起点。经过后训练的 ERNIE 5.5 Flash 将随后推出，我们也期待社区在这一基座上探索领域适配、推理强化与 Agent 训练等方向。
