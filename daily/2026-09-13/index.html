Cognition 发布 SWE-2：基于 Kimi K3 后训练的编程模型
MarkTechPost
Cognition（Devin 背后公司）发布迄今最强编程模型 SWE-2，基于月之暗面 Kimi K3（2.8T 参数开源模型）做强化学习后训练，在 FrontierCode 1.1 Main 取得 50.0% 得分，距 Fable 5.1 仅 1 个百分点、成本却低 64%。这是其首个支持可选推理强度档位的模型，三个档位在同一次 RL 运行中训练完成。相较 SWE-1.7（基于 Kimi K2.7 后训练），本次将 RL 扩展到多万亿参数区间，基础模型参数量近 3 倍，RL 在 K3 之上仍有 5～6 个百分点提升空间。SWE-2 无开放权重、无独立 API，仅运行于 Devin（Desktop/CLI 已上线，Web 与 Fusion 陆续推出）。
果蝇语言模型 FLM：将完整果蝇连接组接入 1.2B 冻结 LLM
MarkTechPost
开发者发布 Fly Language Model（FLM），号称世界首个『果蝇语言模型』：将完整雄性果蝇脑连接组（MaleCNS v1.0，166,700 节点、25,582,938 条有向边）耦合到冻结的 LiquidAI LFM2.5-1.2B-Instruct 骨干，架构名为 GPF（Generative Pre-trained Fly）。系统本质是在语言模型上嫁接一个储层计算机：图、骨干与随机投影全部固定，仅训练约 27.8 万参数的读出层（占骨干 0.024%）。作者坦言，去掉果蝇连接组的参数匹配对照模型表现反而略好，并明确否认自己是首个连接组语言模型。项目以 MIT 许可开源，可本地运行（macOS/Linux，MPS/CUDA/CPU，无需 API key）。

AWS 开源后台 AI Agent 收件箱 Pizza Bot
MarkTechPost
AWS 开源异步 AI Agent 工作台 Pizza Bot，面向在用户离开时持续运行的后台 Agent 任务。它将已完成结果与待决事项归入邮件式收件箱（All/Unread/Action 三视图），支持手动、cron 与 webhook 触发，断线后仅补跑一次错过的 cron 而非全部重放。底层基于 DeepAgents + LangGraph 做有状态执行，Hono API 服务运行时，Electron/浏览器/终端客户端共用 React 界面，LangGraph checkpoint 保留线程状态与审批暂停。已在 Amazon 内部服务超 2000 人，现以 Apache 2.0 开源，提供 macOS/Windows/Linux 桌面端与本地/独立后端部署。
Harness 内的上下文工程：对抗长程任务溢出与目标丢失的 4 机制
MarkTechPost
本文拆解 Agent harness 中对抗长程任务『上下文溢出』与『目标丢失』的四类机制：压缩（compaction）、记忆策略、上下文预算（context budgeting）与待办状态（todo-state）。AWS 自主云编码 Agent 设计指南指出，浅层 Agent 在约 200 次工具调用、一小时任务中会出现上下文溢出与注意力涣散；更大上下文窗口并非解药——Chroma 评测 18 个 LLM 发现输入越长性能越不稳定，Anthropic 亦强调注意力预算随 token 递减。文章逐一对比 LangChain Deep Agents、Claude Code、Manus、OpenAI Codex、Amazon Bedrock AgentCore 的具体实现阈值，说明 harness（而非模型）才是把浅层循环变成深度 Agent 的关键层。
基于 NVIDIA cuML/RAPIDS 的机器学习工作流实现
MarkTechPost
本教程以 NVIDIA cuML 演示 GPU 加速机器学习工作流：先通过 cuml.accel 以极少代码改动加速现有 scikit-learn 负载，再深入原生 cuML API 与 CuPy/cuDF 互操作；基准对比 PCA、K-Means、近邻搜索、逻辑回归、随机森林、DBSCAN 等任务的 CPU 与 GPU 实现；并构建基于 UMAP、t-SNE、HDBSCAN 的流形学习与聚类管线，用 FIL 做高吞吐森林推理、验证 GPU 版 SHAP 解释、以元估计器做超参优化，最后序列化模型并考察 GPU/CPU 环境间可移植性。整体展示 RAPIDS 如何将熟悉的数据科学与 ML 任务在 GPU 上提速落地。

个性化智能体强化学习框架上线，8B模型盲测第一
量子位
中科大与阿里巴巴团队提出 PARPO（Personalized Anchor Reward-Decoupled Policy Optimization），把个性化正式纳入 Agentic RL 的训练期优化目标，解决『同一 query 不同用户偏好不同』的难题。方法含三部分：PSGM 偏好对齐技能演化图记忆（User/Skill/Tool/Scenario/Trajectory 异构图）在 rollout 前提供用户相关经验；两阶段偏好解耦奖励模型在 rollout 后产出个性化奖励；PARPO 优化器将通用质量与个性化偏好拆为两条 advantage 轨道更新。在 ETAPP/ETAPP-Hard/SJAgent 上（Qwen3-4B/8B）评测，8B 模型 Judge 分达 0.8333，15 位人类专家与 4 组 LLM judge 盲测均第一，主增益来自更强的用户对齐。

量子位
