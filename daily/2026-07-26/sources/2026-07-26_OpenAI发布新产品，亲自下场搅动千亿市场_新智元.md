# OpenAI发布新产品，亲自下场搅动千亿市场

> 原文链接：https://mp.weixin.qq.com/s/Ev-5uhlj0bUZnNwzz9ubWQ
> 公众号：新智元

新智元报道

AI 客服在最近两年被认为是 Agent 商业化落地的为数不多的最佳场景之一，借助 RAG 技术，成本远低于人工客服，也让我们过上了被迫绞尽脑汁「转人工」的生活。

这一高速增长的领域，市场价值是千亿级人民币，而作为 API 提供商的 OpenAI 看着自己的大客户 Salesforce 赚得盆满钵满，也坐不住了，开始亲自下场，绕开赚差价的中间商，或将为这一市场的格局带来翻天覆地的变化。

OpenAI 7 月 22 日发布了 Presence，一款面向企业的 Agent 部署产品，覆盖语音和文字两种渠道。

发布附带一份实战成绩单：Presence 已在 OpenAI 自己的英文客服热线 1-888-GPT-0090 上运行，75% 的来电无需人工介入即可解决。

上线数周，AI 服务质量超过了人工客服的考核基准。

OpenAI 把 Presence 定义为「经过实战验证的企业产品」——企业拿到的是模型加一整套策略定制、安全护栏、效果评估和持续改进机制。

这款产品的发布也把 OpenAI 推到了一个新位置：Salesforce、Zendesk、Intercom 这些用 OpenAI 模型搭建自家 AI 客服方案的公司，现在要和自己的模型供应商争同一批企业客户。

一个 Agent 只干一件事

Presence 的产品设计从限制开始。

每个 Agent 只负责一项具体任务：处理账单纠纷的 Agent 看不到保险理赔的数据，解决 IT 工单的 Agent 接触不到财务系统。

企业为每个 Agent 划定权限，规定它能做什么、什么操作需要审批、什么情况转人工。

上线之后，Codex 接手改进。

它分析生产环境中的对话和转接数据，定位 Agent 处理薄弱的环节，生成修改建议。

团队审核测试通过后，更新才推到线上。

这套闭环在 OpenAI 内部已跑出具体数字：Codex 驱动的改进循环 10 天内把客服热线的人工转接率降低了 15 个百分点。

151 亿美元的切口，778 亿美元的桌子

AI 客服是增长最快的企业软件细分领域之一。

Polaris Market Research 数据显示，2026 年全球 AI 客服市场规模约 151 亿美元，年复合增速 25.6%。

https://www.polarismarketresearch.com/industry-analysis/ai-for-customer-service-market

Gartner 从成本端给了另一个参照：到 2026 年底，AI 预计帮全球客服中心节省 800 亿美元人力开支。

https://www.gartner.com/en/newsroom/press-releases/2022-08-31-gartner-predicts-conversational-ai-will-reduce-contac

单次交互的成本差距已经拉开：AI 自助服务 1.84 美元，人工辅助 13.50 美元，差了超过 7 倍。

151 亿美元只是更大盘子的一个切口。

据 Fortune Business Insights，整个客服中心软件市场 2026 年约 778 亿美元。

https://www.fortunebusinessinsights.com/industry-reports/contact-center-software-market-100840

桌上坐满了成熟玩家：Salesforce 的 Agentforce 按每次对话约 2 美元计费，Zendesk 和 ServiceNow 各有成型的 Agent 方案，NICE 在 2025 年以约 9.55 亿美元收购了对话式 AI 公司 Cognigy。

开头提到的供应链矛盾落到具体产品上更清楚。

Intercom 的 Fin 用 OpenAI 和 Anthropic 的模型做编排，Kustomer 的 KIQ Agents 构建在 OpenAI 模型之上。

这些公司是 OpenAI 的 API 付费客户，而这次 OpenAI 发布的 Presence 让双方从上下游变成了直接竞争对手。

5 月，OpenAI 推出了部署公司，做企业 AI 咨询和集成。

https://openai.com/index/openai-launches-the-deployment-company/

Presence 是这条路线的产品化延伸。

目前，定价未公布，覆盖地域未说明，是否兼容第三方模型没有提及。

Presence 的商业逻辑指向一个正在成型的行业判断：模型 API 的利润率在走低，部署和治理层才是高毛利区间。

OpenAI 先拿自己的客服热线做了一个样板间，75% 的独立解决率是一张能放上谈判桌的数字。

下一步盯两个节点：

定价公布后，多少企业愿意绕过 Salesforce、Zendesk 直接找 OpenAI 买客服方案；

Presence 的自助版什么时候上线。

只有摆脱 FDE

（Forward Deployed Engineer，前线部署工程师）

驻场的产能瓶颈，778 亿美元的桌子才真正和它有关。
