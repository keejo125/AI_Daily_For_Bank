MarkTechPostGoogle DeepMind

Laya 决策引擎开发指南：零样本决策与概率校准
MarkTechPost
Laya 是 Convai Innovations 开源的决策引擎（421M 参数编码器），以非自回归方式在单次前向传播中完成分类、打分、是非判断等“零样本决策”并输出校准概率，被称为 TypeSafe Jev 的开源替代。本文用银行意图分类数据集 CLINC150 实测：仅以意图描述做零样本路由即达 0.804 准确率，与需每意图 3–10 条标注训练的 TF-IDF 分类器相当；裸意图名（0.878）优于带描述版本，反转选项顺序会改变 4.2% 的个别答案。文章同时揭示默认温度隐患——11 项以上选择题被钳制为 0.5 导致过度自信（ECE 0.102），在自有验证集上仅拟合所测分桶温度后降至 0.059；并给出按选项数分桶设置弃权门限、在标注数据上设定是非题阈值的工程建议，对构建生产级路由 / Agent 决策层有参考价值。
Meta 开源 Rebalancer：日均处理约 4000 万分配问题的 C++ 求解器
MarkTechPost
Meta 开源 Rebalancer——一个带 Python 接口的 C++ 分配问题求解库（Apache 2.0），用于在高可用与可扩展约束下决定“对象放哪个桶”。其设计将问题规格与求解分离：规格编译为表达式图，再由局部搜索（并行、每秒数百万次评估）或 MIP 求解器（FICO Xpress / Gurobi / HiGHS）求解。Meta 内部已运行 9 年，日均处理约 4000 万分配问题、30+ 种 formulation，P99 在 26.5 万对象 / 3200 桶上为 12 秒；并提供 Docker 化调试 UI Rebalancer Explorer。对标 Google OR-Tools，其优势是一套分配规格同时跑局部搜索与 MIP。

代码量，不代表AI生产力！XP创始人：开发者真正的工作，发生在代码生成之后
51CTO技术栈
XP 创始人、TDD 先驱 Kent Beck 在 Prodacity 2026 演讲中指出，AI 生成代码越来越便宜，但“代码量 / PR 数”离任务结果还隔两层：Effort→Output→Outcome→Mission。Agent 能快速补齐接口、页面并使测试变绿，却掩盖旧数据迁移、权限继承、支付幂等等生产风险。他提出以 Features（当下功能）与 Futures（系统下一步的可选择性）区分代码结构，主张每完成一个功能后停下来消除重复、补可观测性、检查边界，把开发者工作从“写实现”移向“限定意图、审查 Diff、验证风险”。对长期系统，一次性 Spec 驱动易退化为瀑布，需以小步部署—观察—迁移形成闭环。
