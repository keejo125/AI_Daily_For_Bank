# 3 天4大展馆、120 余场论坛：没听完的云栖内容，交给 Agent 补齐

> 原文链接：https://www.infoq.cn/article/BYZ2ODFXp1VSxvJxHotq
> 来源：InfoQ

2026云栖大会于9月24日圆满结束。3 天，3大主论坛、120 余场分论坛、4 大展馆集中展开，有限的现场时间与密集的内容供给之间，很多参会者都会面临一个问题：现场只能抵达其中一部分，更多论坛与展区内容无法在会期内完整获取，剩下的内容怎么办？现在，不必再从头翻完所有直播回放。大会期间上线的云栖参会 Skill 已延伸到会后——让 Agent 领取分论坛与展区总结，再按主题、日期或嘉宾筛选，想看什么，直接找什么。

01 大会结束，Agent 还在继续整理

大会期间上线的云栖参会 Skill，覆盖了会期内与会后的不同信息需求。会期内，云栖参会 Skill 是参会助手：查议程、推荐论坛、订阅直播。会期结束，它的任务随之切换到内容整理：领取分论坛与展区总结，把重磅发布、嘉宾观点、关键数据和圆桌结论整理成结构化笔记。没到场的论坛、没及时看的回放，都可以通过 Agent 重新找回来。

02 四步，把展台论坛总结交给 Agent

1、复制以下命令：
npx skills add QianWen-AI/apsara-conference-2026
在您常用的 Agent 工具中粘贴并发送

（所有支持 Skill 的 Agent 均可使用，推荐千问办公、Qoder）

2、以自然语言输入："给我领取所有分论坛的摘要"

3、授权千问 AI 平台的 CLI

4、授权完成，Agent 即可获取已整理的论坛摘要。
想按主题看、按日期找，或只关注某位嘉宾，都可以直接筛选；对具体议题有疑问，也可以继续追问。

03 不只给摘要，还能筛选和追问

集中获取：100 余场论坛的核心内容可在 Agent 对话窗口中统一查看，无需逐场翻阅回放。结构化呈现：发布、观点、数据与圆桌结论被分类整理，重点信息更容易定位。围绕问题追问：从一次性阅读转向按需检索，用户可直接就具体主题深入了解、持续追问。覆盖展区内容：除分论坛外，展区总结也可领取，进一步补全大会信息。

04 智以致用，云栖的知识持续流动

大型技术会议的内容价值，并不会随议程结束而停止。真正影响信息获取效率的，除了内容数量，还有能否在会后重新找到、快速理解，并围绕具体问题继续使用。

云栖参会 Skill 将分散的论坛与展区总结接入 Agent，让未能到场的内容拥有统一入口。大会已经落幕，但围绕 4大主题展馆、120 余场论坛等形成的观点、发布与讨论，仍可按需查阅和追问。

如需领取总结，可将以下命令发送至 Agent：
npx skills add QianWen-AI/apsara-conference-2026

安装完成后，即可获取相应内容。
