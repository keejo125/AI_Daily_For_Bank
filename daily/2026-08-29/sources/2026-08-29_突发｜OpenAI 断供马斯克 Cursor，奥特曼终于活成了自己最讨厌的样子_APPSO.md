# 突发｜OpenAI 断供马斯克 Cursor，奥特曼终于活成了自己最讨厌的样子

来源：APPSO
原文链接：https://mp.weixin.qq.com/s/BQmit8AI3zQzYdBvo5EGzg

马斯克刚花 600 亿美元把 Cursor 收入 SpaceX 旗下，两周之后的今天，
OpenAI 就决定结束与 Cursor 延续近四年的模型合作。
就在刚刚，OpenAI 发布官方声明称，已经通知 SpaceX，
计划逐步终止向 Cursor 直接提供 OpenAI 模型的合同，拟定的最终停止日期为 2026 年 11 月 12 日。
按照 OpenAI 的说法，这已经是现有合同允许的最长通知期限，目的在于给依赖 GPT 模型的 Cursor 开发者留下更多迁移时间。
此外，OpenAI 还明确表示，接下来发布的新模型将不会继续提供给 Cursor，
其中就包括正在开发中的下一代模型 Astra。
OpenAI 给出的理由是无法确认 SpaceX 会按照 OpenAI 的服务条款使用其技术。
一场持续多年的马斯克与 OpenAI CEO Sam Altman 的恩怨，因此第一次直接影响到了数千万开发者日常使用的 AI 编程工具。
闪婚两周，惨遭 OpenAI 光速断供
OpenAI 此时突然退出，和 Cursor 两周前发生的控制权变化直接相关。
今年 6 月 16 日，SpaceX 宣布豪掷 600 亿美元股权收购 Cursor 母公司 Anysphere。8 月 14 日，双方刚刚完成交割，Cursor 摇身一变成了 SpaceX 的全资子公司。
结果呢？
整整 15 天，一天都不带耽搁的。
OpenAI 卡着合同里「控制权变更」的审查窗口期，一套连招行云流水：启动条款、通知 SpaceX、公开断供，主打一个毫不留情 (战术后仰)。
对于给出的分手理由，OpenAI 甚至懒得打马虎眼，直接指名道姓点向了老马：
「我们无法确认 SpaceX 会遵守我们的服务条款。」
说白了，就是觉得老马这个人「信誉分不够」。
OpenAI 还在声明里把旧账全给翻了出来：
当年老马拿下 Twitter 之后，立马撕毁了和 OpenAI 的协议；今年早些时候老马在法庭上宣誓作证，还亲口承认过 xAI 曾违规用过 OpenAI 的条款。
被开发者封为 Codex「赛博义父」的 OpenAI 核心成员 Tibo Sottiaux，直接在 X 上冷酷甩出一个词：
「Trust.」 (信任没了)
言下之意：Cursor 是个好应用，但架不住它现在的爹是马斯克啊！
Cursor 联合创始人 Michael Truell 赶紧出来打圆场，表示团队还在努力沟通，并委屈巴巴地表示：我们可是 OpenAI 最早的一批核心客户，四年兄弟情，一直把你们当赛博中立服务商……
(可怜巴巴.jpg)。
「自带干粮」还能用，但下一代模型别想了
看到这里，每天靠 Cursor 疯狂 Vibe Coding 的打工人可能已经汗流浃背了：
明天上班我的 IDE 就要彻底和 ChatGPT 说拜拜了吗？
倒也没有那么绝对。
按照 Tibo 的说法，OpenAI 留了最长的缓冲期到 11 月 12 日。大限之后，普通开发者依然可以走 BYOK (自带 API Key) 的路子在 Cursor 里继续跑 GPT。
但对于 Cursor 自身来说，便利性无疑是大打折扣。
过去 Cursor 能一路狂飙，靠的就是官方打包批发顶尖模型，用户开箱即用，抹平了所有的 Token 门槛。统一供给一旦被砍，Cursor 就没法在底层 Agent 里肆意烧 Token 调优，产品的丝滑体验直接被砍了一刀。
更致命的打击还在后头，下一代大模型 Astra 的断供。
8 月 7 日 OpenAI 刚内部偷跑了 Astra 的测试战力，在 Agentic Coding 和网络安全领域简直是外挂级存在，甚至触及了安全框架里的「Critical」最高防御等级。
这玩意儿原本是各家 IDE 梦寐以求的版本答案，现在 OpenAI 态度极其明确：如此危险的「赛博大杀器」，怎么可能交到竞对老马的手里？
Cursor 以前是「万家灯火我全都要」的六边形战士，左手 OpenAI、右手 Claude、脚踩 Gemini。现在背靠 SpaceX，虽然注入了 xAI 的算力血包和 Grok 系列，但也彻底告别了中立身份。
历史是个轮回
这一出「断供连续剧」，去年大家其实也看过相似的剧情。
把时间线倒回 2025 年，当时 OpenAI 传出要花 30 亿美元收购另一家 AI 编程当红炸子鸡 Windsurf。
消息刚冒头，Anthropic 就坐不住了，连夜给 Windsurf 限流，削减了 Claude 3.5 Sonnet 和 Claude 3.7 Sonnet 的直供权限，连 Claude 4 的大门都没让它摸到。
当时 Anthropic 联创 Jared Kaplan 的回应那叫一个理直气壮：
如果 Windsurf 成了 OpenAI 的资产，我们再通过它给对手递刀子，这商业逻辑不觉得很抽象吗？
一年之后，攻守易形了老弟！
一年前是 Anthropic 防着 OpenAI，一年后轮到 OpenAI 防着马斯克。
有一说一，曾经看起来像云计算一样中立的模型 API，正在逐渐带上竞争关系。
曾经，大家以为底层大模型的 API 就像水电煤一样中立，应用层只要把工作流和 UI 体验打磨到极致，就能靠着「多模型缝合」躺着数钱。
但现实给所有人上了一课：当 OpenAI 掏出 Codex、Anthropic 端出 Claude Code，上游的大神们自己也下场做应用了。既当裁判，又当运动员。
对于 AI 编程工具而言，上游模型正在成为和芯片、云服务一样需要长期管理的战略资源。
Cursor 被 SpaceX 收购之后拥有了更多算力、自有模型和资本支持，却也失去了过去作为独立公司的部分中立身份。OpenAI 在交易完成十四天后宣布退出，第一次让这笔 600 亿美元收购的另一项成本变得具体。
当基础模型公司同时向应用层扩张，而头部应用又不断被模型公司收入旗下，「一个工具装下所有顶级模型」的开放格局，正在变得越来越难维持。
