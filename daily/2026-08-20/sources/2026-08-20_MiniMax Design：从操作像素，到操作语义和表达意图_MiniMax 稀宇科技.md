# MiniMax Design：从操作像素，到操作语义和表达意图

> 原文链接：https://mp.weixin.qq.com/s/vMmhr2rCeBC_dM_tBdks1A
> 来源：MiniMax 稀宇科技

今天，我们向大家介绍 MiniMax Design。
MiniMax Design 是一款把多模态模型能力变成真实可用的生产力的 Harness。用户提出创作需求后，它能够理解目标、拆解任务、调用相应的模型与 Skills，完成从素材处理、生成和编辑到最终交付的完整过程。
MiniMax 原生多模态视频模型 H3 为 MiniMax Design 提供了新的能力基础，它已经验证了 MiniMax 在多模态理解、视频生成、视频编辑、参考控制等方面的模型能力，尤其适合 Video Editing 等对理解、控制与修改要求更高的场景。
我们希望通过 MiniMax Design 进一步释放 H3 的生产力，把这些能力进一步组织进真实的商业内容生产流程。
对多模态生产力的两点思考
对于多模态生产力的未来，我们有两个思考。
第一个
思考
是，未来的创作与修改不会停留在传统意义上的 Editing，而是语义层面的创作与修改。用户不必精确告诉系统每个像素和时间点如何变化，只需要表达高层意图，模型理解“想要什么”，再完成生成、修改、重组和编辑。
长期来看，我们相信自然语言会成为人与多模态内容交互的核心接口。用户负责表达意图，系统负责理解意图，并完成具体的生成、修改和组织。
第二个
思考
是，多模态模型的下一步进展将来自对更复杂 Context 的理解和使用。
H3 这一代已经初步具备了理解多模态上下文的能力：用户可以同时提供几张图片、几段视频和一些指令，由模型理解不同内容之间的关系。
未来，模型需要理解的 Context 会从一次输入扩展到整个 Project。它将包括整个项目的历史和多轮对话，所有图片、视频、音频与剧本，人物、场景、道具和品牌资产，不同版本及其修改记录，以及用户长期形成的风格和偏好。
这和语言模型的发展类似：Context 长度不是唯一变化，真正的变化是模型能否有效理解并利用复杂 Context。
从单次生成走向 Agent 驱动
的完整工作流
基于我们的技术判断和 H3 开源后在社区中看到的真实需求，我们推出 MiniMax Design。
围绕 H3 原生构建
MiniMax Design 围绕 H3 原生构建，把对 H3 能力边界、输入方式和使用方法的理解沉淀在 Agent 与 Skills 中。面对一项具体任务，系统会判断需要提供哪些文字、图片、视频和音频，哪些内容应该作为参考，哪些部分需要保留、增强或修改，再将创作需求转化为适合 H3 执行的素材、指令和能力组合。
例如，在制作 PV 或 MV 时，MiniMax Design 会根据内容主题、音乐节奏和参考素材确定视觉风格与分镜，再准备人物、场景和动作参考，将不同镜头整理成适合 H3 执行的素材和提示词。制作电影片头或特效包装时，MiniMax Design 则会进一步拆解文字、图形、镜头运动和转场效果，明确需要保留、增强和修改的内容，再组合使用 H3 的生成、参考控制和视频编辑能力。
擅长商业内容任务
MiniMax Design 擅长处理目标明确、涉及多个制作环节，并且需要持续生成和修改的商业内容任务，我们介绍几种常见的使用场景：
当品牌需要快速测试创意、批量迭代投放素材时，可以把商品信息、目标人群和传播需求交给 MiniMax Design。在 KOC、UGC、种草或品牌短片中，Agent 会围绕不同卖点、受众和内容平台规划脚本与镜头，继续完成素材生成、剪辑和字幕，让一套商品素材更快变成多个可用版本。
运动鞋电商广告
外卖品牌创意短片
如果用户希望把教案、课件，知识点或传统故事制作成视频，也可以直接把现有材料交给 MiniMax Design。Agent 会先梳理内容结构和讲解顺序，再组织配音、画面和动画表达，把文字材料逐步制作成完整的知识视频或 MG 动画。
皮影戏版故事插画
英语教学短视频
当企业或创作者需要制作 PV、MV、电影片头、特效包装、角色宣传片等创意短片时，任务往往对视觉风格、镜头连续性和后期修改有更高要求。MiniMax Design 可以发挥 H3 在生成、参考控制和视频编辑方面的能力，由 Agent 规划整体创意与镜头，Skills 完成具体制作环节，减少创作者在多个专业工具之间来回切换的成本。
PV 制作
MV 制作
这些列举的 Case 是商业内容生产中几类常见的任务。对于目标明确、过程可拆解，并且需要连续调用多种能力的内容需求，MiniMax Design 都可以从理解目标开始，持续推进生成、编辑和修改，直到形成可以交付的内容。
补全从分镜到成片的
创作流程
一条可以交付的视频，除了生成镜头，还需要在生成前确定构图、人物关系和镜头运动，在生成后完成剪辑、字幕和整体装配。
3D
导演台：
对于画面调度要求较高的内容，MiniMax Design 提供了 Agent 3D 导演台。用户描述场景、人物动作和镜头要求后，MiniMax Design 可以在 3D 空间中摆放角色、调整姿态与机位，并从不同视角检查画面。用户也可以随时手动调整，确认构图和人物关系后，系统再将结果作为 H3 生成视频的参考，把一部分试错提前到分镜阶段，减少无效生成，提高画面的可控性。
镜头完成之后，MiniMax Design 还可以继续完成自动剪辑和字幕添加，将生成的素材组织成完整视频。
接入
开
源生态：
H3 模型开源后，社区不断涌现出新玩法，越来越多的创作者和开发者加入了 H3 生态，我们精选了部分 H3 工作流并集合在 MiniMax Design 中，也邀请更多创作者加入到开源生态中探索。
对于已经使用 ComfyUI 的专业创作者，原有的本地部署方式和成熟
工作流
也可以接入 MiniMax Design。
选择云端或本地运行方式，在 MiniMax Design 中打开你的工作流，还可以让 Agent 根据对话协助调整，包括编辑工作流节点，以及调整生成参数等精细化设置，实现更佳精确和高质量的效果。
