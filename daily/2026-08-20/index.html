本文讨论 AI 产品如何从"能做出来"走向"真正落地"。核心观点：模型与编码工具已大幅降低原型门槛，单纯拥有功能难成长期优势，客户真正付费的是可嵌入业务流程、持续交付的结果。文章建议把顺序倒过来——先问清客户想要什么结果、出现在什么流程、最小切口做出可运行交付，再产品化；并用五个问题验证需求（客户是谁、是否高频够痛、价值能否量化、能否进工作流、为何信赖持续使用）。 好的 AI 场景需自然嵌入已有系统，并在反馈中持续迭代，把交付过程标准化、固化为壁垒；通用功能易被大平台整合，更可靠壁垒来自客户数据、行业流程与长期关系。文末以线下社交、知识共创、AI 短视频剪辑三个案例说明聚焦清晰人群与结果的重要性。
“Anthropic不再是AI圈的信仰”
InfoQ
本文结合市场研究机构 TickerTrends 等数据，分析 Claude Code 与 OpenAI Codex 的竞争格局与用户口碑变化。文章称开发者使用注意力自 4 月起向 Codex 倾斜，有用户反馈 Claude Code 体验下滑、AI 腔严重，而 Codex 理解力强、直接执行。 TickerTrends 估算截至 8 月 10 日 Claude Code 年化经常性收入（ARR）达 151.2 亿美元、Codex 为 88.3 亿美元，但 7 月 6 日至 8 月 10 日 Codex ARR 增幅超 50%、Claude Code 约 6%，两者差距缩小。文章还引用 Sacra、SemiAnalysis 数据，指出 Anthropic 通过 Amazon Bedrock 等间接渠道的 ARR 占比已超 40%，按总额确认收入可能高估利润贡献；并讨论企业版订阅按量计费导致开销超支的现象。文末附开发者对模型效果与定价的不满评论。
人工智能的五个悖论
腾讯研究院
腾讯研究院资深专家闫德利撰文梳理人工智能领域的五个悖论。预测悖论：图灵奖得主、企业家等对 AI 未来的预测常不准确或过于保守，AGI 实现时间在企业家的激进与学者的悲观间分化明显。就业量化悖论：OECD、IMF、高盛等机构的 AI 就业影响测算结果差距巨大（约 0.4%–67%），且 AI 影响难以从多重因素中剥离。 生产率悖论：欧盟劳动生产率近年近乎零增长，美国增速仅相当于长期平均水平，印证"索洛悖论"的时滞解释。数据价值悖论：数据被誉为"新石油"却难以货币化，我国 136 家上市公司数据资源入表金额仅 37.86 亿元。工业革命悖论：数十年来诸多技术被赋予"第四次工业革命"使命，而工业革命多为事后叙事。文章呼吁理性看待 AI 能力与影响。
