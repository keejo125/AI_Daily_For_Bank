# 三驾马车日度趋势泳道图

把《AI 早报》按日重新组织成**与月度三驾马车泳道图（前瞻月报/view）一致**的可视化：
横轴是**日**，泳道是**三驾马车下的 12 个细分项**，每条**趋势**画一条跨越其首现→末现日的条带，
按生命周期状态着色，用来回答三个问题——**有没有新趋势（萌芽）、它在发展还是休眠**。

> 本目录独立于「月度月报」（`前瞻月报/view/`）和「存量日报」（`AI-Daily-for-bank/daily/`），不改动它们任何文件。

## 一眼怎么读

- **泳道**：范式 / 智能体能力 / 新基建；新基建进一步展开为 模型·算力·知识·安全 4 个子行。
- **横轴**：每个日报日（MM-DD）。鼠标横向扫，就是时间推进。
- **每条趋势条带**：左端=首次冒头日，右端=最后出现日；条带越长，持续越久。
- **红色「新」角标**：标在每条趋势**首次冒头**那一天——扫过去看到红点，就是那段时间冒出的新动向。
- **状态色**（与月度口径完全一致）：
  - **萌芽**（红字）：首现日 == 最新日，只在最近一天冒头、还没续上。
  - **持续**（实色 + ▶）：活跃到最新日且之前就出现过——**在发展**。
  - **休眠**（斜纹虚线 + ✕）：最后活跃日早于最新日——**已退潮**。
- **点击**任一条带或左侧标题，展开「演进脉络」：该趋势代表性的几篇早报（日期/来源/标题/原文链接）。
- **悬浮**显示该趋势的演进样例。
- **工具栏**：按「马车 / 来源」筛选；`仅看活跃（隐藏休眠）`看正在发展的；`仅看新趋势（近期冒头）`聚焦近期才冒出来的；`重置筛选`复原；**`审核模式`**开关进入人工审核（见下）。

## 趋势是怎么来的（口径）

日报没有像月度那样人工维护的 `trends.json`，这里**自动抽取**：

1. **主题种子词**（`TOPIC_SEEDS`）：模型/算力/知识/安全/智能体 各细分下「具体到能成为一条趋势」的词
   （如 模型里的 GPT/Claude/DeepSeek/多模态/世界模型，智能体里的 多Agent/虚拟同事/自进化/CodeBuddy）。
2. **英文产品/模型名**（`EN_PRODUCTS` + 带版本号自动捕获，如 `GPT-5.6`、`Opus5`、`Fable5`）：发现新模型/产品动向。
3. **范式 = 事件模板**（`PARADIGM_TEMPLATES`）：范式不再用「落地/治理/人才」这类维度占位词当趋势，
   而是用**共现窗口正则**抽取具体范式动作（如 `设立AI组织`、`AI原生战略/经营重构`、`一把手/高管谈AI战略`、
   `AI治理/合规体制`、`All in AI / AI First`、`规模化推广/标杆落地`、`数字员工/岗位智能体上岗`、
   `CAIO/首席AI任命`、`AI人才培养/认证`）。同一模板命中的多篇早报聚合成一条以**动作标签**命名的趋势。
4. 合并 → 按日聚合（出现天数 / 命中文章数达阈值）→ 去重 → 每条趋势算 `first/last` 日与生命周期状态，并取代表样例。

> 说明：中文趋势主题由种子词与范式模板覆盖；要新增主题，往 `build_daily.py` 的 `TOPIC_SEEDS` 或
> `PARADIGM_TEMPLATES` 里加词即可。早期版本用 jieba 做中文自由新词发现，因无命名实体模型时分不清
> 「趋势主题」与高频内容词，噪声过大，已停用。

## 人审核 → 智能体调整判断（反馈闭环）

范式分类初期难免有偏差。本视图内置一条**人机协同回路**：

1. **智能体自判**：`build_daily.py` 按事件模板自动判出范式趋势并打 `conf` 置信度。
2. **人审核**：点工具栏 `审核模式`，范式每条趋势下方出现审核控件——
   - 下拉框选目标细分；`保存`（细分未变=确认，变了=改类）；`非范式`（认为它不该属于范式，剔除）。
   - 已审核的趋势打 `✓已审` 徽标。
3. **智能体调逻辑**：每次审核通过 `/api/feedback` 写入 `feedback.json`，并**立即重跑 `build_daily.py`+`sync.py`**，
   把人的结论固化进下一次判断——`reject` 的趋势不再出现，`reclass` 的细分被采纳，`confirm` 的标记已审。
   后续日报再跑时，智能体会"记住"这些审核，分类越改越准。

`feedback.json` 结构示例：
```json
{ "paradigm": {
    "设立AI组织": { "decision": "confirm", "sub": null, "at": "2026-08-05T12:33:11", "by": "human" },
    "All in AI / AI First": { "decision": "reject", "sub": null, "at": "2026-08-05T12:33:24", "by": "human" }
} }
```

## 每日增量更新

```bash
cd projects/AI-Daily-for-bank/三驾马车日视图
python3 build_daily.py     # 生成 daily-trends.json（--check 只看统计）
python3 sync.py            # 注入 index.html
```

## 本地预览 + 审核（推荐，含反馈 API）

```bash
cd projects/AI-Daily-for-bank/三驾马车日视图
python3 server.py 8732     # 托管静态文件 + 提供 /api/feedback 审核回路
# 浏览器打开 http://localhost:8732/index.html
```

> 审核功能依赖 `server.py`（标准库 `http.server`，无需额外依赖）。直接双击 `index.html` 也能看，
> 但审核提交需要该服务在线。`server.py` 在收到审核后会自动重跑 `build_daily.py` 与 `sync.py`。

## 文件结构

| 文件 | 作用 |
|------|------|
| `daily-trends.json` | **唯一事实源**。趋势列表 + meta（天数/马车/来源/统计）。 |
| `build_daily.py` | 读日报 `classification.json` → 自动抽取趋势（含范式事件模板）→ 生成 `daily-trends.json`；并消费 `feedback.json`。 |
| `sync.py` | 把 `daily-trends.json` 幂等注入 `index.html`（内嵌数据，双击即可看；http 下自动读最新 json）。 |
| `server.py` | 本地服务：托管静态文件 + `/api/feedback`（接收审核→落盘→重跑→返回新 DATA）。 |
| `feedback.json` | **人工审核记录**（人审核 → 智能体调整判断的载体）。初始为 `{"paradigm":{}}`。 |
| `index.html` | 渲染页面（数据已内嵌，并支持审核模式）。 |
